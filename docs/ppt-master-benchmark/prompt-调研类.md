### 调研主题与固定数据（必须原样使用，不得改写数字）

**主题**：2025 年中国 Z 世代（18–28 岁）现制咖啡消费调研

**调研方法**：

- 线上问卷 + 6 城线下深访
- 样本量 **n = 1,200**（一线 40% / 新一线 35% / 二线 25%）
- 字段：频次、单次消费、品牌偏好、决策因素

**核心数据（必须在幻灯片中体现）**：

| 指标 | 数值 |
|------|------|
| 周均消费频次 | 3.2 次 |
| 单次客单价（元） | 28.6 |
| 最关注因素 Top1 | 口味 62% |
| 最关注因素 Top2 | 性价比 48% |
| 最关注因素 Top3 | 门店氛围 31% |
| 品牌认知 Top3 | 瑞幸 78% / 星巴克 71% / 库迪 54% |
| 愿意尝试新品牌 | 是 67% / 否 33% |

### 8 页固定结构（一页一主题，不得合并或拆分）

1. **封面**：主标题 + 副标题「2025 中国 Z 世代现制咖啡消费调研」+ 日期 2025-05
2. **调研背景与方法**：行业背景 2 要点 + 方法表（n=1200、城市分布）
3. **样本画像**：年龄 18–28、性别比 52:48、职业分布（学生 38% / 白领 45% / 其他 17%）
4. **核心发现一：消费频次与客单价**：3.2 次/周、28.6 元；简短解读 2 句
5. **核心发现二：决策因素**：口味 62%、性价比 48%、氛围 31%；柱状或条形对比图（SVG 形状即可）
6. **品牌对比**：瑞幸 78% / 星巴克 71% / 库迪 54%；一句竞争格局结论
7. **建议与机会**：3 条可执行建议（针对连锁品牌）
8. **结语**：一句话总结 + 「谢谢」
