# 生成页测试用例（`/create/generate`）

> 覆盖生成入口 **演示文稿 / 生成图片** 两 Tab 的 UI 与交互验收。  
> 功能说明见 [`功能开发说明书.md`](功能开发说明书.md) §2；路由见 [`AI生成向导.md`](AI生成向导.md)。

**测试环境：** 登录后访问 `/create/generate`  
**最后更新：** 2026-05-31（双 Tab 胶囊/模板对齐）

---

## 1. 输入框宽度与对齐

| # | 用例 | 步骤 | 预期 |
|---|------|------|------|
| 1.1 | Tab 切换不改变输入框宽度 | 在「演示文稿」「生成图片」间来回切换 | 主内容区始终 `max-w-3xl`；输入框宽度一致，**不因 image 模式变宽** |
| 1.2 | 模板区与输入框同宽 | image 空态，观察分割线下方 3 张模板卡片 | 三列卡片总宽度与上方输入框对齐，**不撑宽容器** |

---

## 2. 生成图片 Tab — 空态布局

| # | 用例 | 步骤 | 预期 |
|---|------|------|------|
| 2.1 | 垂直顺序 | 选「生成图片」，输入框留空 | **胶囊（上）→ 输入框 → 分割线 → 3 张模板卡片（下）** |
| 2.2 | 三胶囊存在 | 同上 | 可见：**图片比例**、**颜色**、**风格** 三个下拉 |
| 2.3 | 模板内容 | 点击任一模板卡片 | `topic` 填入主体/环境/光线/风格全文；卡片选中高亮 |
| 2.4 | 模板与风格联动 | 选带 `suggestedStyle` 的模板（如「橘猫窗台」） | **风格**下拉同步为对应值（如「扁平插画」） |
| 2.5 | 清空恢复空态 | 删除输入框全部文字 | 分割线 + 模板区重新出现；选中态清除 |

---

## 3. 图片比例下拉（Gamma 风格）

| # | 用例 | 步骤 | 预期 |
|---|------|------|------|
| 3.1 | 展示格式 | 打开「图片比例」下拉 | 每项为 **小矩形图标 + 比例数字**（如 `9:16`），**不含中文后缀**（不应出现「移动端」「网页」等） |
| 3.2 | 选项数量 | 展开比例列表 | 共 **6 项**：`1:1`、`16:9`、`4:3`、`3:4`、`4:5`、`9:16` |
| 3.3 | 选中态 | 选择任一项 | 触发器显示对应图标 + 比例；列表项左侧有 check |
| 3.4 | 横屏映射 | 选 `16:9` 或 `4:3`，填提示词 →「编辑提示词」→ 生图页生成 | API `viewport_preset_id` 为 `web-1280` |
| 3.5 | 竖屏/方图映射 | 选 `9:16`、`3:4`、`4:5` 或 `1:1` 后生成 | API `viewport_preset_id` 为 `mobile-375` |

---

## 4. 风格下拉

| # | 用例 | 步骤 | 预期 |
|---|------|------|------|
| 4.1 | 首项为「无」 | 打开风格下拉 | **第一项为「无」** |
| 4.2 | 默认选中 | 首次进入 image Tab（或清空草稿后刷新） | 风格默认 **「无」** |
| 4.3 | 不拼风格元数据 | 风格选「无」，填提示词 → 生图页 → 生成 | 最终 prompt **不追加** `风格：…` 行（除非用户已在正文写「风格」） |
| 4.4 | 有风格时拼入 | 风格选「商务专业」等，正文无「风格」关键词 → 生成 | 提交 prompt 追加 `风格：商务专业`（或等价元数据行） |

---

## 5. 色调下拉（deck / image 共用）

| # | 用例 | 步骤 | 预期 |
|---|------|------|------|
| 5.1 | 首项为「无」 | 打开色调下拉（两 Tab） | **第一项为「无」** |
| 5.2 | 默认选中 | 首次进入或清空草稿后刷新 | 色调默认 **「无」** |
| 5.3 | 选项完整 | 展开色调列表 | 无 / 经典白粉 / 浅灰 / 深色 / 多彩 |
| 5.4 | image 拼入 | image 选「深色」，正文无「色调」「颜色」→ 生图 | 提交 prompt 追加 `色调：深色` |
| 5.5 | deck 不预设 | deck 色调选「无」→ 全量生成 | 不强制 classic_white 背景覆盖 |

---

## 6. 有输入态布局（演示文稿 / 生成图片一致）

> 胶囊 **始终固定在输入框上方**，不随输入增高而下移、不贴屏幕最底。有输入时示例/模板隐藏，居中「编辑提示词」。

| # | 用例 | 步骤 | 预期 |
|---|------|------|------|
| 6.1 | 胶囊位置固定（deck / image） | 两 Tab 输入短/长内容并滚动页面 | 胶囊 **始终在输入框上方**；**sticky** 滚动时贴顶可见；**不**出现在编辑按钮下或屏幕最底 |
| 6.2 | 短内容 | 输入「1」「12」 | 输入框约单行；居中「编辑提示词」；胶囊仍在输入框上方 |
| 6.3 | 长文增高 | 粘贴长文 | 输入框随内容增高至上限后框内滚动；胶囊位置 **不变** |
| 6.4 | 隐藏示例/模板 | 有输入时 | deck 示例 / image 模板隐藏 |
| 6.5 | 删字回退 | 删至空 | 恢复示例/模板；布局与空态一致 |

---

## 7. 演示文稿 Tab — 空态（与 image 对齐）

| # | 用例 | 步骤 | 预期 |
|---|------|------|------|
| 7.1 | 胶囊顺序 | 演示文稿 Tab，输入框留空 | **比例 → 色调 → 页数 → 语言**（比例带左侧图标） |
| 7.2 | 空态顺序 | 同上 | **胶囊 → 输入框 → 分割线 →「选择提示词模板」卡片** |
| 7.3 | 模板卡片 | 点击任一 deck 模板 | `topic` 填入主题/受众/结构/风格；卡片选中高亮 |
| 7.4 | 预览占位 | 模板无 preview_url | 卡片顶部显示 4:3 占位区（图标+「预览图」） |
| 7.5 | 无底部按钮 | 空态 | **不显示**「编辑提示词」 |
| 7.6 | 管理端同步 | 管理端新建/启用 deck 模板 | 生成页空态可见新模板 |

## 8. 跳转与草稿

| # | 用例 | 步骤 | 预期 |
|---|------|------|------|
| 8.1 | image 跳转 | image Tab 填词 →「编辑提示词」 | 进入 `/create/generate/image`；左栏预填 `topic` |
| 8.2 | 比例同步 | 生成页选 `16:9` → 跳转生图页 | 生图页尺寸控件显示 `16:9`（图标+比例） |
| 8.3 | deck 跳转 | deck Tab 填词 →「编辑提示词」 | 进入 `/create/generate/review` |
| 8.4 | 刷新恢复 | 有输入后刷新页面 | `topic` 与胶囊选项从 session 草稿恢复（`type` 仍默认演示文稿 Tab） |

---

## 9. 生图页联动（`/create/generate/image`）

| # | 用例 | 步骤 | 预期 |
|---|------|------|------|
| 9.1 | 尺寸控件 | 进入生图页 | 左栏「尺寸」为 **ImageAspectRatioSelect**（非「9:16 移动端」文案 select） |
| 9.2 | 生成成功 | 填 prompt →「生成图片」 | 右栏展示结果；所用 prompt 展示含色调/风格元数据（若已选且正文未含） |
| 9.3 | 裁切与复制 | 生成后点击图片 / 点复制 | 裁切弹窗、复制到剪贴板正常 |

---

## 10. 已知限制（测试时勿报假缺陷）

| 项 | 说明 |
|----|------|
| API 比例 | 后端仅 `mobile-375` / `web-1280` 两种 preset；6 种比例 UI 按横/竖屏映射，非 6 种独立像素尺寸 |
| 风格/颜色 | 为 prompt 元数据拼入，非独立 API 字段 |
| 默认 Tab | 进入页始终默认「演示文稿」，不恢复草稿 `type` |
