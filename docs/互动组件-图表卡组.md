# 互动组件：图表卡组（上下翻转）

> 最后更新：2026-06-01 · 状态：**已实现（P1）**  
> 需求追踪见 [`需求清单.md`](./需求清单.md) 第九节（CS-01~06）。

在**单页画布内**展示多张数据图：白底卡片堆叠形成景深，当前卡片完整显示饼图或柱状图，浏览时可**上下滑动或点击按钮**切换前后图表。编辑器内可增删卡片、编辑标题与数据。

---

## 一、使用入口

| 入口 | 行为 |
|------|------|
| 素材面板 → **特殊组件 → 图表卡组** | 在当前页插入默认 2 张示例图（饼图 + 柱状图） |
| 选中组件 → 工具栏 **编辑卡组** | 打开全屏编辑弹窗 |
| 双击画布上的图表卡组 | 同上，打开编辑弹窗 |
| 预览 / 分享 `/s/{slug}` | 上滑或 ▼ 切换下一张；下滑或 ▲ 切换上一张 |

编辑模式下，选中组件后顶部 **内嵌拖拽条**（`drag_indicator`）可移动位置；卡片区域内切换不会触发整页翻页。

---

## 二、数据模型

画布元素类型：`chartStack`（与单张 `chart` 并存，旧项目不受影响）。

```json
{
  "type": "chartStack",
  "x": 28,
  "y": 80,
  "width": 320,
  "height": 260,
  "content": {
    "cards": [
      {
        "id": "c_abc123",
        "title": "您对未来「吃谷」消费的期望",
        "chartType": "pie",
        "labels": ["增加", "维持", "减少"],
        "values": [45, 35, 20]
      },
      {
        "id": "c_def456",
        "title": "您对「吃谷」规划和安排的建议",
        "chartType": "bar",
        "labels": ["规划1", "规划2", "规划3", "规划4"],
        "values": [60, 40, 55, 70]
      }
    ]
  },
  "style": {
    "background": "#ffffff",
    "chartColor": "#005daa"
  }
}
```

| 字段 | 说明 |
|------|------|
| `cards[].chartType` | `bar` 柱状图；`pie` 饼图（多色分段） |
| `cards[].labels` / `values` | 数据项标签与数值，长度应对齐 |
| `style.chartColor` | 柱状图主色；饼图使用内置多色盘 |
| `activeIndex` | **不持久化**，仅在浏览时运行时维护 |

数据存于 `canvas_json`，后端 API 无需改动。

## 三、视觉与交互

### 堆叠样式

- 最多可见 **3 层**（当前 + 后方 2 张），**后大前小**：
  - 当前前台：`scale(0.88)`，左右内缩 18px，贴底，z-index 最高
  - 后方第 1 张：`scale(0.96)`，左右内缩 10px，上移 16px
  - 后方第 2 张：`scale(1.04)`，全宽，上移 32px，最大
- 后方卡片通过更大缩放 + 更小左右内缩，从顶部与两侧「包裹」前台卡片；视口 `overflow: visible` + 顶部留白保证后方边缘可见
- 所有可见卡片均渲染完整标题 + 图表
- 切换时前台卡片**滑至最后方槽位**（而非消失），后方卡片同步前移缩小（450ms 缓动），无空白帧

### 切换方式

| 模式 | 行为 |
|------|------|
| 演示 / 预览 | 上滑 → 下一张（前台后移放大、后方前移缩小）；下滑 → 上一张；底部 `当前/总数` 与 ▲▼ 按钮 |
| 编辑器画布 | 同上可预览切换；选中后顶部内嵌拖拽条移动组件；双击或工具栏编辑数据 |

切换动画约 450ms：前台卡片移至后方槽位、后方卡片前移，完成后更新 `activeIndex`；`toNext` 阶段额外渲染即将进入堆栈的第 4 张卡片，避免切换中间态闪白。

### 2026-06-01 修复摘要

| 问题 | 修复 |
|------|------|
| 后方卡片未包裹前台 | 槽位增加 `insetX` 差分；视口改为 `overflow: visible` 并加大顶部留白 |
| 编辑器内无法拖拽 | 拖拽条改为组件**内部**顶部条，避免被 `overflow: hidden` 裁切 |
| 切换时前台卡片消失 | 修正 `buildNextOverrides`（前台→槽位 2、避免两卡同槽）；`toNext` 可见范围扩展至 `activeIndex+3` |

## 四、编辑器弹窗

`ChartStackEditorModal.vue` 全屏布局：

- **左侧**：卡片列表，可增删
- **中间**：当前卡片实时预览（`SimpleChart`）
- **右侧**：标题、图表类型、数据 textarea（每行 `标签,数值`）

保存后回写 `element.content.cards` 至画布并同步云端 `canvas_json`。

## 六、验收标准（CS）

1. 素材面板可插入「图表卡组」，默认 2 张示例图  
2. 编辑弹窗修改标题/数值后，画布与预览同步  
3. 演示页上下滑动能切换，堆叠景深正常  
4. 卡组内切换不触发整页翻页  
5. 原有单张 `chart` 元素与旧模板不受影响
