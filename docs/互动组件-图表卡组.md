# 互动组件：图表卡组（上下翻转）

> 最后更新：2026-05-31 · 状态：**已实现（P1）**  
> 需求追踪见 [`需求清单.md`](./需求清单.md) 第九节（CS-01~06）。

在**单页画布内**展示多张数据图：白底卡片堆叠形成景深，当前卡片完整显示饼图或柱状图，浏览时可**上下滑动或点击按钮**切换前后图表。编辑器内可增删卡片、编辑标题与数据。

---

## 一、使用入口

| 入口 | 行为 |
|------|------|
| 素材面板 → **特殊组件 → 图表卡组** | 在当前页插入默认 2 张示例图（饼图 + 柱状图） |
| 选中组件 → 工具栏 **编辑卡组** | 打开全屏编辑弹窗 |
| 双击画布上的图表卡组 | 同上，打开编辑弹窗 |
| 预览 / 分享 `/s/{slug}` | 上滑或 ▼ 切换下一张；下滑或 ▲ 切换上一张 |

编辑模式下，组件顶部 **拖拽条** 可移动位置；卡片区域内切换不会触发整页翻页。

---

## 二、数据模型

画布元素类型：`chartStack`（与单张 `chart` 并存，旧项目不受影响）。

```json
{
  "type": "chartStack",
  "x": 28,
  "y": 80,
  "width": 320,
  "height": 260,
  "content": {
    "cards": [
      {
        "id": "c_abc123",
        "title": "您对未来「吃谷」消费的期望",
        "chartType": "pie",
        "labels": ["增加", "维持", "减少"],
        "values": [45, 35, 20]
      },
      {
        "id": "c_def456",
        "title": "您对「吃谷」规划和安排的建议",
        "chartType": "bar",
        "labels": ["规划1", "规划2", "规划3", "规划4"],
        "values": [60, 40, 55, 70]
      }
    ]
  },
  "style": {
    "background": "#ffffff",
    "chartColor": "#005daa"
  }
}
```

| 字段 | 说明 |
|------|------|
| `cards[].chartType` | `bar` 柱状图；`pie` 饼图（多色分段） |
| `cards[].labels` / `values` | 数据项标签与数值，长度应对齐 |
| `style.chartColor` | 柱状图主色；饼图使用内置多色盘 |
| `activeIndex` | **不持久化**，仅在浏览时运行时维护 |

数据存于 `canvas_json`，后端 API 无需改动。

## 三、视觉与交互

### 堆叠样式

- 最多可见 **3 层**（当前 + 后方 2 张）
- 当前：`scale(1)`，不透明
- 第 2 张：`scale(0.94)`，上移 14px，略透明
- 第 3 张：`scale(0.88)`，上移 26px，更透明

### 切换方式

| 模式 | 行为 |
|------|------|
| 演示 / 预览 | 上滑 → 下一张；下滑 → 上一张；底部 `当前/总数` 与 ▲▼ 按钮 |
| 编辑器画布 | 同上可预览切换；顶部拖拽条移动组件；双击或工具栏编辑数据 |

切换动画约 300ms：当前卡片向上淡出，下一张从下方进入并放大至前台。

---

## 四、编辑器弹窗

`ChartStackEditorModal.vue` 全屏布局：

- **左侧**：卡片列表，可增删
- **中间**：当前卡片实时预览（`SimpleChart`）
- **右侧**：标题、图表类型、数据 textarea（每行 `标签,数值`）

保存后回写 `element.content.cards` 至画布并同步云端 `canvas_json`。

## 六、验收标准（CS）

1. 素材面板可插入「图表卡组」，默认 2 张示例图  
2. 编辑弹窗修改标题/数值后，画布与预览同步  
3. 演示页上下滑动能切换，堆叠景深正常  
4. 卡组内切换不触发整页翻页  
5. 原有单张 `chart` 元素与旧模板不受影响
