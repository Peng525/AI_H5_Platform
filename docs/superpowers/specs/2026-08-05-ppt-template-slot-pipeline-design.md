# PPT 模板槽位化与快速生成链路设计

## 1. 目标

将当前 PPT 生成能力升级为管理员维护模板、普通用户选择模板、AI 自动规划内容、本地确定性套版的混合生成链路。

核心目标：

- 管理员上传 `.pptx`，解析后先进入可编辑预览，确认后上架。
- 普通用户只能浏览、预览和选择已上架模板，不能上传、修改或删除模板。
- 模板复杂背景和品牌装饰保持高保真；标题、正文、图片、图表保留为可拖拽、缩放和替换的画布元素。
- 复用单页 AI 生成中的要点、段落、卡片、图片配文字四类内容协议。
- 默认由 AI 为每页自动选择内容类型，用户可设置全局软偏好。
- 常规 5–10 页演示在 60–120 秒内进入可编辑结果页。
- 默认生成只进行一次文本模型规划；仅必要页面请求生图或特殊视觉增强。

## 2. 当前问题与根因

### 2.1 快速 JSON 生成

当前快速模式由 LLM 返回结构化 JSON，再由前端固定编译器生成画布元素。优点是速度快、元素可编辑，但页面只能从有限的固定布局中组合，容易显得简单和重复。

### 2.2 Premium PPT Master 生成

当前 Premium 流水线执行 Strategist 后，对每一页串行调用 Executor 生成完整 SVG。10 页通常需要 10 次以上模型请求，并且失败时单页可能重试，导致整体耗时达到 5–6 分钟。

生成后的 SVG 在导入 H5 时被压成一个铺满画布的 `image` 元素。视觉效果可能更丰富，但用户不能编辑其中的标题、正文、图片或图表。

### 2.3 上传模板继承不足

当前 PPTX 导入只抽取封面、目录、内容、结束等代表 SVG，Executor 再根据参考 SVG 重写整页。模板仅作为提示参考，模型仍可能改变原模板的图形关系、留白、字体层级和图片区域。

## 3. 选定方案

采用“模板背景层 + 可编辑内容槽位”的混合方案。

模板中的复杂装饰、品牌纹理、不可编辑矢量图形合并为背景 SVG；标题、正文、图片、图表等内容区域转换为槽位。槽位最终映射为现有画布系统支持的元素，因此可以直接复用拖拽、缩放、图层、文本编辑、图片裁切和自动保存能力。

不再让 Executor 为每一页重新生成完整 SVG。默认生成链路只让 Strategist 一次返回整套页面内容和内容类型，然后由本地渲染器绑定模板槽位。

## 4. 权限与模板生命周期

模板生命周期：

1. 管理员在独立的“PPT 模板管理”页面上传 `.pptx`。
2. 后端校验格式和大小并解析模板。
3. 解析结果保存为草稿，生成封面预览、页面类型和槽位数据。
4. 管理员进入模板预览编辑器调整槽位。
5. 管理员点击预览，检查模板各页面类型。
6. 管理员手动上架。
7. 普通用户模板列表只返回已上架模板。
8. 管理员可以下架、重新编辑或删除模板。

权限规则：

- 模板上传、修改、上架、下架和删除接口使用 `require_admin`。
- 普通用户列表接口继续使用 `get_current_user`，只返回 `enabled=true` 模板。
- 用户生成页删除上传按钮和文件输入控件。
- 上传成功不自动公开，必须经过管理员预览和上架。

## 5. 模板数据结构

新增持久化的 PPT 模板元数据，建议使用数据库记录管理生命周期，文件系统保存模板资产。

模板记录主要字段：

```json
{
  "id": "ppt_tpl_xxx",
  "slug": "corporate_blue",
  "title": "企业科技蓝",
  "description": "适用于商业汇报",
  "category": "business",
  "status": "draft",
  "canvas_width": 1280,
  "canvas_height": 720,
  "preview_url": "/api/v1/演示/ppt-模板/preview/...",
  "source_file": "template.pptx",
  "created_by": 1
}
```

每种页面类型对应一个模板页面定义：

```json
{
  "page_type": "content",
  "name": "左文右图内容页",
  "background_asset": "03_content_background.svg",
  "slots": [
    {
      "id": "title",
      "type": "text",
      "role": "title",
      "x": 96,
      "y": 72,
      "width": 520,
      "height": 90,
      "style": {
        "fontSize": 36,
        "fontWeight": 700,
        "color": "#102A43"
      },
      "editable": true
    },
    {
      "id": "body",
      "type": "text",
      "role": "body",
      "x": 96,
      "y": 196,
      "width": 500,
      "height": 420,
      "contentModes": ["bullets", "paragraph", "cards"]
    },
    {
      "id": "hero_image",
      "type": "image",
      "role": "image",
      "x": 640,
      "y": 0,
      "width": 640,
      "height": 720,
      "fit": "cover",
      "editable": true
    }
  ]
}
```

页面类型至少包含：

- `cover`
- `toc`
- `section`
- `content`
- `closing`

管理员可复制页面类型并创建多个内容页变体。

## 6. 管理员模板预览编辑器

编辑器复用现有 `CanvasElement`、`useSlideCanvas` 和画布工具栏，不重新开发拖拽缩放引擎。

管理员可以：

- 查看模板页面缩略图。
- 选择背景层和槽位层。
- 移动、放大、缩小文本、图片和图表槽位。
- 将图片槽位调整为占满整个右半边，例如 `x=640, y=0, width=640, height=720`。
- 设置图片的 `cover`、`contain` 或裁切模式。
- 修改槽位角色、默认样式和允许的内容类型。
- 锁定背景层，避免误操作。
- 新增或删除槽位。
- 保存草稿、打开全尺寸预览并上架。

模板预览编辑操作只修改槽位坐标和样式，不调用大模型。

## 7. 用户生成交互

用户选择“生成 PPT”后，在提示词输入框下方显示已上架 PPT 模板。

模板卡片显示：

- 封面预览
- 模板名称
- 分类和适用场景
- 页面类型数量

用户必须选择一个模板后才能继续生成。

生成设置增加“内容布局偏好”：

- `auto`：AI 自动逐页选择，默认值。
- `bullets`：偏好要点。
- `paragraph`：偏好段落。
- `cards`：偏好卡片。
- `image_text`：偏好图片配文字。

偏好为软约束。Strategist 应优先使用用户偏好，但目录、章节、封面或内容明显不适合时可以选择其他类型。

## 8. 快速生成数据流

```mermaid
flowchart LR
  User["用户输入与模板选择"] --> Plan["一次 Strategist 请求"]
  Plan --> Validate["结构校验与归一化"]
  Validate --> Map["页面类型与模板页面匹配"]
  Map --> Bind["本地槽位绑定"]
  Bind --> Fit["文本测量与溢出适配"]
  Fit --> Images["必要图片并发生成"]
  Images --> Project["保存可编辑画布项目"]
  Project --> Editor["进入结果编辑器"]
```

Strategist 一次返回全部页面：

```json
{
  "title": "项目标题",
  "pages": [
    {
      "page_type": "content",
      "content_mode": "cards",
      "title": "核心能力",
      "body": "",
      "points": [
        {"title": "能力一", "body": "说明"},
        {"title": "能力二", "body": "说明"}
      ],
      "image_prompt": ""
    }
  ]
}
```

后端完成以下确定性处理：

1. 校验页数、页面类型和内容类型。
2. 根据 `page_type + content_mode` 选择模板页面变体。
3. 将内容绑定到 `title/body/image/chart` 槽位。
4. 使用现有文本测量逻辑处理换行、字号收缩和裁剪。
5. 生成 `canvas_elements`，背景层设置为锁定元素。
6. 只对带有必要 `image_prompt` 的页面执行生图。
7. 保存项目后立即进入编辑器。

## 9. 单页模板功能复用

整套生成与单页生成功能统一使用以下 `content_mode`：

| UI 名称 | 协议值 | 主要数据 |
|---|---|---|
| 要点 | `bullets` | `points[]` |
| 段落 | `paragraph` | `body`，可带辅助 `points[]` |
| 卡片 | `cards` | 2–4 个结构化 `points[]` |
| 图片配文字 | `image_text` | `image_prompt + body/points` |

复用前端 `GenerateTemplatePicker` 的选项定义，抽取共享常量，避免单页和整套生成分别维护两套映射。

## 10. 性能目标与预算

当前主要耗时是每页串行 Executor 请求。新链路取消默认逐页 Executor。

10 页常规生成预算：

| 阶段 | 目标耗时 |
|---|---:|
| Strategist 一次生成整套内容 | 20–45 秒 |
| JSON 校验、模板匹配和槽位绑定 | 5–15 秒 |
| 文本适配和画布构建 | 5–15 秒 |
| 0–3 张必要配图并发生成 | 0–30 秒 |
| 数据库存储和结果页加载 | 5–15 秒 |
| 合计 | 35–120 秒 |

性能策略：

- 默认只调用一次文本模型。
- 生图默认限制为最多 3 张，并发执行。
- 用户未要求配图且页面不需要视觉素材时不生图。
- PPTX 导出改为进入编辑器后的后台可选任务，不阻塞首次结果。
- 对模板解析结果、背景资产和页面定义进行缓存。
- 生成进度按真实阶段展示，不使用逐页 Executor 进度文案。

1–2 分钟是目标服务等级，不承诺外部模型或网络异常时绝对满足。超时后应显示明确错误并允许用户返回编辑或重试。

## 11. 兼容与降级

- 旧的固定 JSON 模板继续用于未选择 PPT 模板的内部兼容场景，但用户 PPT 生成入口默认要求选择模板。
- 旧 Premium Executor 保留为“高级视觉增强”可选能力，不再作为默认主链路。
- 模板槽位数据缺失时禁止上架，而不是退化为整页图片后公开。
- 某张图片生成失败时，使用模板默认图片或占位素材，不阻塞整套演示。
- Strategist 返回非法内容时允许一次格式修复请求；仍失败则终止任务，不循环重试。

## 12. 测试与低成本验证

默认不执行真实大模型整套生成测试。

自动化验证：

- 管理员上传接口权限测试。
- 普通用户上传返回 403。
- 草稿模板不出现在用户列表。
- 上架模板出现在用户列表。
- 槽位移动、缩放和保存的数据往返测试。
- 四种内容类型到槽位的绑定测试。
- AI 自动选择与用户软偏好的提示词协议测试。
- 文本溢出、图片全右栏、背景锁定测试。
- 使用固定 Strategist JSON fixture 验证 5–10 页完整项目生成，不产生模型费用。
- 前端构建和后端单元测试。

必要的真实测试限制为一次：

- 使用 5 页、小内容、无生图或最多 1 张图。
- 记录 Strategist、套版、保存和首屏加载耗时。
- 验证生成结果采用所选模板，核心槽位可编辑。
- 只有静态 fixture 链路通过后才执行这次真实调用。

## 13. 验收标准

- 普通用户页面不存在模板上传入口。
- 普通用户无法调用模板上传和管理接口。
- 管理员可以上传 PPTX，进入预览编辑器并调整槽位。
- 图片槽位可移动、缩放并设置为占满右半边。
- 管理员确认上架后，模板立即出现在用户生成页。
- 用户选择模板后，模板 ID 和内容偏好进入生成任务。
- AI 默认逐页自动选择内容类型，并尊重用户软偏好。
- 生成结果使用所选模板背景和槽位，标题、正文、图片、图表可编辑。
- 5–10 页常规生成的设计目标为 60–120 秒。
- 默认生成不再逐页调用 Executor。
- 自动化验证不产生真实大模型费用；最多进行一次必要的 5 页真实链路验证。
