## 二、当前实现依据优先级（从高到低）

Agent 判断"当前系统到底是什么样"时，按此顺序采信：

1. **当前源码与自动化测试**
2. **最新 Gate 核查报告** —— `开发计划/`
3. **Accepted 状态的 ADR** —— `项目决策记录/`
4. 当前开发计划
5. **当前规范** —— `当前规范/`
6. 其他 `docs/` 文档
7. 历史方案、调研与 Benchmark

### 冲突裁决规则

- **文档与源码冲突** → 以 **源码 + 最新 Gate 核查结果** 为准
- **旧方案与 Accepted ADR 冲突** → 以 **ADR** 为准
- **历史文档不得覆盖当前实现事实**
- 任何标有 `⚠️` 的文件，**不得作为当前实现依据**

## 三、主生成链路（当前）

以 G0 源码核查为准，**当前生成按钮**走的是单次规划调用，不存在逐页 Executor / Designer：

```text
AiGenerateReview
  → ai-生成-orchestrated
  → orchestrate_strategist.yaml
  → 单次 LLM 调用
  → structured_json
  → compileStructuredSlide
  → canvas_elements
  → CanvasElement（编辑器）
```

> ⚠️ 历史链路上的 `Strategist → Executor N → Designer`（N+2 次调用）属于**旧编排方案**，仅见于历史文档与 `ppt-master-benchmark/`。
> 旧同步 `ai-生成` 接口仍保留，但不是当前生成按钮的行为。

## 四、文档分类总览

| 目录 / 位置 | 回答什么问题 | 说明 |
|---|---|---|
| `开发计划/` | **本轮具体做什么？** | G0、G1 及后续 Gate 的实施方案与验收结果 |
| `项目决策记录/` | **当初为什么这么决定？** | ADR-001 ~ ADR-010，全部 `Accepted`，质量完好 |
| `当前规范/` | **系统现在是什么样？** | ⚠️ **第一轮暂空（刻意）**。须通过准入标准 A/B/C，见 `当前规范/README.md` |
| `旧方案/` | **曾经怎么做（已废弃）？** | 明确不再作为当前实现路线，仅作技术历史参考 |
| `简历模块/` | —— | **活跃功能**：独立开发中的产品子功能，与 AI PPT 主线独立 |
| `ppt-master-benchmark/` | —— | 已停止的模型横评；含 Premium 后端**运行时引用**，暂留原位 |
| 根目录散落文档 | —— | 见第五、六、七节 |

> **三个目录不要混**：`当前规范/` = 现在是什么；`项目决策记录/` = 为什么这样决定；`旧方案/` = 曾经怎么做。

## 十一、文档维护提示

- 本文件只维护**指针与可信度**，不复制专项内容，避免出现第二份事实源
- 新增文档时请评估它属于哪一类：**当前实现依据** / **独立功能模块** / **历史参考**
- **历史文档不需要被同步成最新** —— 正确处置是**明确标注它是旧的**，而不是让它追上代码
- 某文档确认完全无用后，再单独归档（按主题，不按月份）
