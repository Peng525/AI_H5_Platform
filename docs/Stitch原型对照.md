# Stitch 原型与实现对照

原型项目：https://stitch.withgoogle.com/projects/11380331898068582338

详细需求见 [需求清单.md](./需求清单.md)。

## 用户端页面

| Stitch 页面 | 路由 | 状态 |
|-------------|------|------|
| 登录/注册 + 拼图验证 | `/login` | ✅ 滑块拼图 |
| 探索模板 + 终端/类型筛选 | `/templates` | ✅ 移动端/网页版，主页无 AI 面板 |
| 我的项目工作台 | `/dashboard` | ✅ 删除确认弹窗 |
| 三栏编辑器 + 可视化拖拽 | `/editor/:id` | ✅ localStorage 持久化 |
| 编辑器素材（PPT 组件） | 工具箱 · 素材 | ✅ 文本框/矩形/表格/图标/图片/图表 |
| 页面画布背景色 | 素材面板 | ✅ 按页保存 |
| Word 风格文本工具栏 | 画布顶部工具栏 | ✅ 字体/字号/颜色/行距等 |
| AI 面板（通道/配额/生成配图/文案） | 编辑器右侧 `AiPanel` | ✅ 配图预览、复制、入画布 |
| AI 创建向导（分步） | `/create` | ✅ |
| 套餐升级 + 扫码支付 | `/upgrade` | ⚠️ 演示/mock（订单已入库） |
| 发布成功 + 链接/二维码 | `/publish/:id` | ✅ 真实 QR |
| H5 全屏预览（手机框切换） | `/preview/:id` | ✅ |
| 分享页 | `/s/:slug` | ✅ |
| 全局导航 + 登出 | `AppShell` | ✅ |

## 管理员端（不对普通用户展示）

| 功能 | 路由 | 状态 |
|------|------|------|
| 管理控制台框架 | `AdminShell` | ✅ 侧栏 + 退出登录 |
| 数据仪表盘（访问/订单/成交额） | `/admin` | ✅ |
| 用户管理（创建/编辑/配额） | `/admin/users` | ✅ |
| 大模型配置（在线保存 `.env`） | `/settings` | ✅ 仅管理员 |
| 管理员登录跳转 | `/login` → `/admin` | ✅ |
