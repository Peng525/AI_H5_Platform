# 简历模块 — 架构决策

## 已确认（2026-07-03）

| 项 | 决策 |
|----|------|
| 架构 | 模块化单体 |
| OCR | PaddleOCR（`RESUME_PADDLEOCR_ENABLED=true` 启用；否则 pymupdf + LLM） |
| 配额 | 每次 generate/optimize **成功**扣 1 |
| 文件 | 5MB / 30 天 / 每用户 5 份 |
| API | 英文 `/api/v1/resume/*` |
| 安全 | Prompt 约束 + 422 违规 |

## 与原微服务方案差异

- 不拆微服务、不用 Kong/MySQL 分库
- UX 为三栏工作台，非独立 Review/Result 三 Tab

## 依赖

- `pymupdf` — PDF 文本
- `python-docx` / `reportlab` — 导出
- `paddleocr` + `paddlepaddle` — 可选 OCR（Docker 体积大，见部署说明）
