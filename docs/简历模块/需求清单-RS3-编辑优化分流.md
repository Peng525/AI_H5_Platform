# 简历模块 — 需求清单 RS3（编辑 / 优化分流 + 上传交互修复）

> **版本**：RS3 · **状态**：待开发 · **前置**：V1 生成入口 + V2 可视化编辑（classic-blue）  
> **关联迭代**：R7 · **任务卡**：[`任务拆解/R7-编辑优化分流.md`](./任务拆解/R7-编辑优化分流.md)

---

## 一、背景与目标

当前生成页将「选模板」「上传旧简历」「输入优化提示词」「AI 生成」混在同一 Tab「简历生成」中，与产品意图不符：

1. **简历编辑**：用户先选视觉模板，进入空白画布手填 / 微调，不需要首屏上传与 AI 诊断。
2. **简历优化**：用户上传已有简历或输入 JD / 优化方向，经 AI 生成后进入带建议侧栏的工作台。
3. **上传交互（RS3-25）**：一行双大卡片；空态居中按钮 + 小字提示；已选后文件名替换按钮与提示，可弹层预览；右下角限制提示文案。

## 三、需求清单

### 3.1 生成页 Tab 重构（P0）

| ID | 需求 | 说明 |
|----|------|------|
| RS3-01 | 移除「简历生成」Tab | `AiGenerateStart` 不再使用单一 `resume` Tab |
| RS3-02 | 新增「简历编辑」Tab | `tab=resume-edit`；下方**仅**展示视觉模板选择器 |
| RS3-03 | 新增「简历优化」Tab | `tab=resume-optimize`；上传 + 提示词 + 生成（原主流程） |
| RS3-04 | Tab 草稿分离 | `useResumeDraft` 增加 `tab` / `mode` 字段，编辑与优化草稿互不覆盖 |
| RS3-05 | 入口链接兼容 | `?tab=resume` 重定向或映射为 `resume-optimize`；列表页「去生成」指向优化 Tab |

### 3.2 简历编辑流程（P0）

| ID | 需求 | 说明 |
|----|------|------|
| RS3-10 | 模板优先展示 | 进入编辑 Tab 即加载 `GET /resume/templates`，无上传区、无提示词区 |
| RS3-11 | 选模板创建简历 | 点击模板 → `POST /resume { template_id }` → **不调用 generate**、**不扣配额** |
| RS3-12 | 跳转编辑工作台 | `/create/generate/resume/:id?mode=edit` |
| RS3-13 | 两栏布局 | 左：AI 提示词助手（可收起）；中：`ResumeEditorPanel`；**右：隐藏**建议侧栏 |
| RS3-14 | 空白画布 | 按 `template_id` 执行 `compile_visual_document`（空 structured + 占位字段） |
| RS3-15 | 左侧 AI 可收起 | 折叠后中间栏占满；展开恢复约 320px 左栏 |

### 3.3 简历优化流程（P0）

| ID | 需求 | 说明 |
|----|------|------|
| RS3-20 | 保留 AI 生成入口 | 上传 PDF/图片 + 提示词 +「生成」按钮 |
| RS3-21 | 提示词模板（可选） | 空态且无上传文件时展示**提示词**模板卡片（填充 prompt）；有输入或已上传后隐藏 |
| RS3-22 | 生成后三栏工作台 | `/create/generate/resume/:id?mode=optimize`（或缺省）：左 AI \| 中编辑 \| 右建议 |
| RS3-23 | 配额与限额 | `generate` 成功仍扣 1 配额；402 / 409 / 422 行为不变 |
| RS3-24 | 列表打开已有简历 | **默认** `mode=optimize`（三栏）；右侧无 sidecar 时显示空态 |

### 3.4 上传交互（P0）

| ID | 需求 | 说明 |
|----|------|------|
| RS3-25 | 双大卡片附件栏 | 左「上传简历」、右「上传工作描述」两张等大卡片 |
| RS3-26 | 空态卡片布局 | 卡片内垂直居中：pill 按钮 + 下方小字 `PDF / 图片 · 最大 5MB` |
| RS3-27 | 已选态替换 | 上传后**隐藏**按钮与提示；卡片居中显示文件名；右上角 × 移除；再次点击同侧空态按钮可换文件（需先移除或覆盖） |
| RS3-27b | 文件名预览 | 本地 `File` 存在时，点击文件名打开 `ResumeFilePreviewModal`（PDF iframe / 图片 img）；仅 session 草稿 fileName 时不可点 |
| RS3-28 | 限制提示 | 附件栏容器右下角固定：「仅支持上传一份简历以及一个工作描述」 |
| RS3-29 | 移除附件 | 卡片右上角 × 移除；三者皆空时恢复提示词模板区（RS3-21） |
| RS3-30 | 生成校验 | 提示词、简历文件、JD 文件至少一项即可生成 |
| RS3-31 | 后端双文件 | `POST /resume` 与 `/generate` 支持 `file_id` + `jd_file_id`；合并文本带 `【简历原文】` / `【工作描述】` 标签 |

**交互示意（简历优化 Tab）：**

```
┌─ 空态大卡片 ─────────┐  ┌─ 已选大卡片 ─────────────┐
│    [ 上传简历 ]       │  │   彭柳峻-产品经理.pdf  [×]│
│ PDF / 图片 · 最大 5MB │  │   （点击文件名 → 预览）   │
└──────────────────────┘  └──────────────────────────┘
                          仅支持上传一份简历以及一个工作描述 ← 右下
[ GenerateTopicInput — 提示词多行 … ]
[ 生成 ]
```

## 四、验收用例（RS3）

1. 生成页可见「简历编辑」「简历优化」，无「简历生成」。
2. 编辑 Tab：仅模板；选 classic-blue → 两栏工作台，右侧无建议，中间为空白模板画布。
3. 优化 Tab：上传 PDF → 卡片内按钮与提示消失，居中显示文件名；点击可弹层预览；× 可移除。
4. 优化 Tab：有附件或提示词输入时，提示词模板区隐藏；移除附件且无输入时模板区恢复。
5. 优化 Tab：点击生成 → 三栏工作台 + 扣 1 配额。
6. 编辑 Tab：选模板创建 → **不扣配额**。
7. 左栏 AI 可收起 / 展开；保存与导出正常。
8. `?tab=resume` 旧链接仍可用（映射到优化 Tab）。
9. `docker build -t ai-h5-platform:local .` 通过。
