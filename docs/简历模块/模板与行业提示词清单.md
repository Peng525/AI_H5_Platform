## API

- `GET /api/v1/resume/industries`
- `GET /api/v1/resume/templates?industry=`
- `GET /api/v1/resume/visual-templates?industry=`
- `POST /api/v1/resume/{id}/generate`  body 必填 `template_id`

## 前端组件

- `ResumeIndustryChips.vue` — 行业筛选
- `ResumeTemplatePicker.vue` — 模板网格（含 `preview_url`）
- `ResumeGenerateHintBubble.vue` — 首次生成气泡
- `components/resume/templates/Template*.vue` — 7 套 Vue 渲染
