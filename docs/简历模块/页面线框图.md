# 简历模块 — 页面线框图

> **RS3 更新**：编辑 / 优化 Tab 分流 + 上传角标。详见 [`需求清单-RS3-编辑优化分流.md`](./需求清单-RS3-编辑优化分流.md)

## 路由

| 路由 | 说明 |
|------|------|
| `/create/generate?tab=resume-edit` | 简历编辑 — 选视觉模板 |
| `/create/generate?tab=resume-optimize` | 简历优化 — 上传 + 提示词 + 生成 |
| `/create/generate?tab=resume` | **兼容** → 映射为 `resume-optimize` |
| `/create/generate/resume/:publicId?mode=edit` | 两栏工作台 |
| `/create/generate/resume/:publicId?mode=optimize` | 三栏工作台（列表进入缺省） |
| `/dashboard/resumes` | 个人简历列表 |

## P1 — 生成入口

### P1a 简历编辑 Tab（`tab=resume-edit`）

```
┌─ AiCreateLayout ─────────────────────────────────┐
│ [演示文稿] [生成图片] [■ 简历编辑] [简历优化]      │
│ 生成 · 您今天想创建什么？                         │
├──────────────────────────────────────────────────┤
│  选择简历模板（PromptTemplateCard 风格）          │
│  [ classic-blue ] [ 模板B … ]                     │
│       ↓ 点击                                      │
│  POST /resume { template_id } → mode=edit 工作台  │
└──────────────────────────────────────────────────┘
```

### P1b 简历优化 Tab（`tab=resume-optimize`）

```
┌─ AiCreateLayout ─────────────────────────────────┐
│ [演示文稿] [生成图片] [简历编辑] [■ 简历优化]      │
├──────────────────────────────────────────────────┤
│ ┌─ 提示词卡片 ─────────────────────────────────┐ │
│ │ [📎 张三_简历.pdf]  [更换] [×]   ← 左上角角标  │ │
│ │ ┌──────────────────────────────────────────┐ │ │
│ │ │ 目标岗位、JD、优化方向…（多行自适应）      │ │ │
│ │ └──────────────────────────────────────────┘ │ │
│ └──────────────────────────────────────────────┘ │
│ （空态且无附件：轻量 [上传简历] 或卡片内上传入口） │
│ ── 空态且无输入且无附件时 ──                      │
│ [ 提示词模板A ] [ 模板B ] [ 模板C ]               │
│                              [ 生成 ] ← 扣配额    │
└──────────────────────────────────────────────────┘
```

**与 V1 线框差异**：

| V1 | RS3 |
|----|-----|
| 大块上传区常驻顶部 | 无附件时轻量入口；有附件时角标在提示词左上角 |
| 上传后按钮变文件名，整块仍占主视觉 | 收起大块区，角标 + 可更换 |
| 单一「简历生成」Tab | 拆为编辑 / 优化 |
| 视觉模板与上传混排 | 视觉模板仅在编辑 Tab |
