# 简历模块 — 页面线框图

> **RS3 更新**：编辑 / 优化 Tab 分流 + 上传角标 + 多页 A4。详见 [`需求清单-RS3-编辑优化分流.md`](./需求清单-RS3-编辑优化分流.md)

## 路由

| 路由 | 说明 |
|------|------|
| `/create/generate?tab=resume-edit` | 简历编辑 — 选视觉模板 |
| `/create/generate?tab=resume-optimize` | 简历优化 — 上传 + 提示词 + 生成 |
| `/create/generate?tab=resume` | **兼容** → 映射为 `resume-optimize` |
| `/create/generate/resume/:publicId?mode=edit` | 两栏工作台 |
| `/create/generate/resume/:publicId?mode=optimize` | 三栏工作台（列表进入缺省） |
| `/dashboard/resumes` | 个人简历列表 |

### P2c 多页 A4 控件（每页下方）

```
┌─ A4 classic-blue 画布 (794×1123px) ──────────────┐
│  个人简历 / motto / 基本信息+照片 / 各区块…       │
└──────────────────────────────────────────────────┘
              [ + 新页 ]    [ 复制 ]
                    │            │
                    │            └─ 复制本页 structured + styles 到下一页
                    └─ 在本页下方插入一页空白 classic-blue 默认占位
```

| 按钮 | 行为 |
|------|------|
| **+ 新页** | 在当前页下方插入空白页（`defaultStructured()` 默认占位） |
| **复制** | 深拷贝当前页内容与单元格样式，插入到下一页 |

多页时页眉显示「第 N 页」。照片 `photo_file_id` 全局共享（各页模板均显示同一张）。

## AI 生成链路（优化 Tab）

```
用户上传 resume + JD（可选）+ 提示词
        │
        ▼
POST /files ──► resume_file_id / jd_file_id
        │
        ▼
POST /resume { source_file_id, jd_file_id, prompt }
        │
        ▼
┌─ LLM 四步链 ─────────────────────────────────────┐
│ 1. resume_parse    解析原文 → structured 草稿     │
│ 2. resume_diagnose 诊断差距 → diagnosis 文本      │
│ 3. resume_generate 重写 → structured_out          │
│ 4. resume_advice   侧栏 → advice + next_steps     │
└──────────────────────────────────────────────────┘
        │
        ▼
compile_visual_document(structured_out, prev_visual)
        │
        ▼
跳转 /create/generate/resume/:id?mode=optimize
三栏工作台：Chat | Editor | AdviceSidebar
```

**编辑 Tab** 不走 LLM：`POST /resume { template_id: "classic-blue" }` → 空白 structured + visual_document → `mode=edit` 两栏工作台。

## 数据模型

| 字段 | 存储 | 说明 |
|------|------|------|
| `structured_json` | DB `resume_version` | **首页**结构化内容；LLM 读写此字段 |
| `visual_document` | API 响应 / `visual_document_json` | 模板元数据 + 多页 |
| `visual_document.pages[]` | 同上 | `{ id, structured, styles }` 每页独立 |
| `visual_document.styles` | 同上 | 首页样式兼容字段（= pages[0].styles） |
| `visual_document.photo_file_id` | 同上 | 全局头像 |
| `visual_document.template_id` | 同上 | 如 `classic-blue` |

**兼容**：旧数据无 `pages` 时，前端 `normalizePages()` 用顶层 `structured` + `styles` 合成单页。

**AI 优化 / 再生成**：仅更新 `pages[0].structured`，其余页保留。

**导出 / 缩略图（当前）**：仍以首页 `structured` 为主；多页完整导出为后续迭代。
