# 简历模块 — 功能开发说明书

## 1. 范围

生成页 Tab → 三栏工作台 → 工作台个人简历列表。英文 API。

## 2. 数据表

- `resume_profiles` — public_id, user_id, title, thumbnail_path, status, expires_at
- `resume_versions` — profile_id, version_no, structured_json, source_file_id
- `resume_messages` — profile_id, role, content, message_type
- `resume_files` — user_id, path, mime, size_bytes, sha256
- `resume_sidecar` — profile_id, advice_json, next_steps_json

## 3. 配额

`check_and_consume` 在 `generate` / `optimize` LLM 成功并 commit 前调用。

## 4. 缩略图

- 在 `generate` / `optimize` / `PUT save`（含 `structured`）成功后，后端将结构化 JSON 渲染为 PNG（Pillow），写入 `resume_profiles.thumbnail_path`（`data/resume/{user_id}/thumbnails/{public_id}.png`）。
- 列表项 `thumbnail_url` 为 `/api/v1/resume/{public_id}/thumbnail`；前端通过带 JWT 的 fetch 转为 blob URL 展示（`<img>` 无法自带 Authorization）。
- Docker 镜像安装 `fonts-noto-cjk` 以正确渲染中文预览。
