# 简历模块 — 需求清单 V2（可视化编辑）

> 在三栏工作台中间栏实现蓝白经典模板 WYSIWYG 编辑。首版 1 套模板 `classic-blue`。

## 模板与布局（P0）

| ID | 需求 | 说明 |
|----|------|------|
| RS2-01 | 蓝白经典模板 | 标题区、基本信息（含证件照）、求职意向、教育/工作/技能/荣誉/自我评价 |
| RS2-02 | 分区蓝条标题 | 每节全宽蓝色标题条 + 白字 |
| RS2-03 | 行组件 1 列 | 整行单格（自我评价等） |
| RS2-04 | 行组件 2 列 | 均分两格（基本信息字段组） |
| RS2-05 | 行组件 3 列 | 均分三格（时间 \| 学校/公司 \| 专业/职位） |
| RS2-06 | 技能进度条 | 可编辑标签 + 进度条（精通/良好） |
| RS2-07 | 模板架构预留 | `template_id` + 注册表，首版仅 `classic-blue` |

## 可视化编辑（P0）

| ID | 需求 | 说明 |
|----|------|------|
| RS2-10 | 点击编辑 | 点击字段进入编辑态，失焦保存 |
| RS2-11 | 选中浮动工具栏 | 字体上方显示：字体、字号、加粗、对齐、颜色 |
| RS2-12 | 样式持久化 | `visual_document.styles` PUT 保存，不扣配额 |
| RS2-13 | 照片上传 | 基本信息区证件照，`POST /files` |
| RS2-14 | 与 AI 协同 | generate/optimize 后刷新画布；手动编辑需保存 |

## 导出（P0）

| ID | 需求 | 说明 |
|----|------|------|
| RS2-20 | PDF 导出 | 与预览布局一致 |
| RS2-21 | Word 导出 | 同结构，含 education/skills/honors |
| RS2-22 | 中文字体 | Docker `fonts-noto-cjk`，PDF 注册中文字体 |
