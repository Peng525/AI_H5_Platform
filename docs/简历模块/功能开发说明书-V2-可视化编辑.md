# 简历模块 — 功能开发说明书 V2（可视化编辑）

## 1. 范围

保留三栏工作台；中间栏由只读预览升级为 **classic-blue** 可视化编辑器。

## 2. 数据模型

### structured（LLM 语义，扩展字段）

```json
{
  "basics": {
    "name": "", "email": "", "phone": "", "summary": "",
    "gender": "", "age": "", "native_place": "", "education": "", "motto": ""
  },
  "job_intention": { "position": "", "city": "", "salary": "", "availability": "" },
  "experience": [{ "company": "", "title": "", "period": "", "bullets": [] }],
  "education": [{ "school": "", "degree": "", "period": "", "details": "" }],
  "skill_bars": [{ "name": "", "level": 80, "label": "精通" }],
  "skills": [],
  "honors": [],
  "self_evaluation": ""
}
```

### visual_document（排版与模板）

```json
{
  "template_id": "classic-blue",
  "photo_file_id": null,
  "styles": {
    "basics.name": { "fontSize": 14, "fontWeight": "bold", "color": "#333", "textAlign": "left" }
  }
}
```

存储：`resume_versions.visual_document_json`（独立列，避免 LLM 覆盖）。

## 3. API

| 方法 | 变更 |
|------|------|
| GET `/api/v1/resume/{id}` | 增加 `visual_document` |
| PUT `/api/v1/resume/{id}` | body 增加 `visual_document?` |
| GET `.../export?format=` | 按 `template_id` 模板渲染 |

## 4. 组件

- `ResumeEditorPanel` — 替换 `ResumePreviewPanel`
- `ClassicBlueTemplate` — A4 蓝白布局
- `ResumeRow` — cols 1/2/3
- `ResumeEditableCell` — 点击编辑 + 选中
- `ResumeFormatToolbar` — 浮动工具条
- `useResumeEditor.js` — 状态与保存

## 5. 编译

`visual_compiler.py`：`normalize_structured()` + `compile_visual_document(structured, existing?)`  
generate/optimize 成功后自动 compile；GET 时若无 visual 则 compile。

## 6. 导出

`export_service.py`：`ClassicBluePdfRenderer` / `ClassicBlueDocxRenderer`  
缩略图与 classic-blue 布局对齐。
