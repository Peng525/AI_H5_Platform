## 二、生成入口（`/create/generate`）

**组件：** `frontend/src/views/create/AiGenerateStart.vue`  
**布局壳：** `AiCreateLayout` — 柔和纵向渐变背景（`from-sky-100/50 via-white to-sky-50/80`）；顶栏 `AiCreateHeader` 半透明毛玻璃（`bg-white/80 backdrop-blur`）。

> **组件级开发逻辑**（状态机、各区块职责、数据流、文件索引）见 **[`生成页组件与开发逻辑.md`](生成页组件与开发逻辑.md)**。  
> **验收用例**见 **[`生成页测试用例.md`](生成页测试用例.md)**。

### 2.1 标题区

居中展示「生成」+「您今天想创建什么？」。

### 2.2 类型 Tab（横向按钮）

| Tab | 点击逻辑 | 后续影响 |
|-----|----------|----------|
| **演示文稿** | `type = 'deck'`；选中态 `border-primary bg-primary/5 text-primary` | 显示胶囊配置、输入框与示例提示 |
| **生成图片** | `type = 'image'` | 显示 **图片比例 / 颜色 / 风格** 三胶囊 + 输入框（宽度与 deck 一致 `max-w-3xl`）；空态分割线下方 **3 张模板卡片**；「编辑提示词」跳转图片页 |

进入页面 **默认选中演示文稿**（不恢复草稿中的 `type`）。Tab 居中排列、适中尺寸（`min-w-[7rem]`）。

### 2.3 胶囊配置（`type === 'deck'`）

白底、`rounded-full` 下拉（页数 / 背景 / 尺寸 / 语言），**左对齐**，**始终固定在输入框上方**（`sticky top-0`；与 image Tab 一致）。

| 控件 | 选项 | 草稿字段 | 后端映射 |
|------|------|----------|----------|
| 页数 | 1–10 张卡片 | `pageCount` | `page_count` |
| 背景 | 经典白粉 / 浅灰 | `background` | `background_preset` → `#fafafa` / `#f0f2f5` |
| 尺寸 | 默认动态 / 传统网页 / 移动端 | `viewportMode` | `auto`→`mobile-375`；`web`→`web-1280`；`mobile`→`mobile-375` |
| 语言 | 简体中文 / English | `language` | `language` |

### 2.3.1 胶囊配置（`type === 'image'`）

白底胶囊，**左对齐**，**始终固定在输入框上方**（`sticky`；与 deck 一致；空态与有输入位置不变）。

| 控件 | 选项 | 草稿字段 | 说明 |
|------|------|----------|------|
| 图片比例 | 1:1 / 16:9 / 4:3 / 3:4 / 4:5 / 9:16（**图标 + 比例**，无中文后缀） | `imageAspectRatio`；同步 `viewportMode` | 横屏→`web-1280`；其余→`mobile-375` |
| 颜色 | 经典白粉 / 浅灰 / 深色 / 多彩 | `imageColor` | 生图页拼入提示词（色调） |
| 风格 | **无**（默认）/ 扁平插画 / 3D质感 / 水彩插画 / 商务专业 / 摄影写实 | `imageStyle` | 选「无」不拼风格；选模板可同步 `suggestedStyle` |

### 2.4 提示词输入与示例（Gamma 两态）

**空态**（`!topic.trim()`）

| 元素 | 行为 |
|------|------|
| 胶囊 | **顶部**（deck 四胶囊 / image 三胶囊） |
| 输入框 | 单行紧凑（~44px），随输入增高，最高 ~192px 后框内滚动 |
| 示例（仅 `deck`） | 分割线 + 示例卡片 +「换一组」 |
| 生图模板（仅 `image`） | 分割线 + **3 张横向模板卡片**（`max-w-3xl`） |
| 主按钮 | **不显示** |

**有输入**（`topic.trim()` 非空）

| 元素 | 行为 |
|------|------|
| 胶囊 | **仍在输入框上方**（`sticky top-0`；deck / image 一致；滚动时不离开视口顶） |
| 输入框 | **仅按内容增高**（短内容 ~44px；上限 ~320px / 35vh 后框内滚动） |
| 示例 / 模板 | **隐藏** |
| **编辑提示词** | 输入框下方居中 |

**生图模板卡片**：点击后将 `formatImagePromptTemplate(tpl)` 写入 `topic`，选中态高亮（`check_circle`）；清空输入后模板区重新显示。

共用：粘贴后滚顶；框外右下角字数；`deck` / `image` 均使用同一输入框。

### 2.5 「编辑提示词」跳转

| 类型 | 启用条件 | 逻辑 | 目标 |
|------|----------|------|------|
| `deck` | `topic.trim()` 非空 | `saveDraft({ type, pageCount, background, viewportMode, language, topic })` | `/create/generate/review` |
| `image` | `topic.trim()` 非空 | `saveDraft({ type, imageAspectRatio, viewportMode, imageColor, imageStyle, topic })` | `/create/generate/image` |

**不调用 API**，仅写草稿并跳转。

### 2.6 入口顶栏与配额

- 顶栏使用 `AiCreateHeader`（`variant="entry"`）：左上「主页」「我的工作台」、居中「欢迎来到 AI H5 平台」、右上 `UserMenu`
- `UserMenu`：桌面端 **用户名下方** 以 `text-xs` 展示 **`tier · 配额`**（如 `专业版 · 配额 97/100`）；窄屏在下拉菜单首行展示
- 工作台二级侧栏用户名下方同样展示配额（`text-xs`）；Dashboard / 模板库主内容区不重复展示

## 四、提示编辑器（`/create/generate/review`）

**组件：** `frontend/src/views/create/AiGenerateReview.vue`

**前置：** 无 `topic` 时 `router.replace('/create/generate')`。

### 4.1 顶栏

| 按钮 | 逻辑 |
|------|------|
| **上一步** | `/create/generate` |

### 4.2 移动端 Tab（`< lg`）

| Tab | 显示区域 |
|-----|----------|
| 设置 | 左栏：文本量、受众、语气、语言、**页数 ±** |
| 内容 | 中栏：自由形式 textarea 或逐张卡片垂直列表 |
| 说明 | 右栏：附加说明 |

桌面端三栏同时展示。

### 4.3 文本量四按钮（核心）

| 按钮 | 点击逻辑 | 是否立即请求 AI |
|------|----------|-----------------|
| **简约** | `textDensity = '简约'` | 否 |
| **精炼** | `textDensity = '精炼'`（默认） | 否 |
| **详细** | `textDensity = '详细'` | 否 |
| **繁琐** | `textDensity = '繁琐'` | 否 |

选中态：主色边框 + 浅蓝底。

**仅在点击「生成」时** 随请求体发送 `text_density`。后端映射（`deck_generation_service.py`）：

| 值 | 写入 LLM `style` 字段的文案 |
|----|------------------------------|
| 简约 | 简洁明了，每页要点极少 |
| 精炼 | 精炼专业，重点突出 |
| 详细 | 详细展开，信息充实 |
| 繁琐 | 详尽全面，覆盖细节 |

同时在 `全量生成.yaml` 约束行出现：`文本密度为 {{ text_density }}`（原始中文值）。

### 4.4 内容栏双模式

内容栏头部 Segmented 切换：**自由形式**（默认） / **逐张卡片**。

| 模式 | UI | 生成行为 |
|------|-----|----------|
| **自由形式** | 单个 textarea，`extraContent` | `content_mode: free`；`topic` + `extra_content` 合并；LLM 按页数与风格自行分页 |
| **逐张卡片** | 中栏 **垂直 N 张卡片**：左上角「页面 i」+ 下方 textarea；可滚动 | `content_mode: per_page`；`page_contents[]` 与 `page_count` 等长；LLM 严格 1 页对应 1 段 |

**切换到逐张卡片**（首次）：弹出 `CardSplitModeDialog`，询问 **是否按当前 N 张卡片分页**：

| 按钮 | 逻辑 |
|------|------|
| **自动分页** | 调用 `splitContentIntoPages(extraContent, pageCount)`：按标题/序号/段落切分并归一化到 **N** 段 |
| **自行分页** | `pageContents = N 个空字符串` |
| **取消** | 不切模式 |

**自动分页规则**（`frontend/src/utils/splitContentIntoPages.js`）：

1. 段数 > N：合并相邻最短段  
2. 段数 < N：拆分最长段直至 N 段  
3. 空文本：N 个空白框  

**切回自由形式**：`pageContents.filter(Boolean).join('\n\n')` 写回 `extraContent`，清空 `cardSplitMode`。

**页数 ±**：位于左栏「语言」下方（非底栏）；增减 `pageCount` 时 `syncPageContents` 对齐数组；逐张卡片模式下减少且末尾页有内容时 ConfirmDialog 确认丢弃。

### 4.5 其他设置控件

| 控件 | 草稿/API 字段 | 发给 LLM 的方式 |
|------|---------------|-----------------|
| **页数 ±** | `pageCount` | `page_count` |
| **写给…** | `audience` | 模板变量 `受众：{{ audience }}`；UI：三行 textarea，聚焦蓝色，超出滚动 |
| **语气** | `tone` | 拼入 `style`：`语气：{tone}`；UI：三行 textarea，聚焦蓝色，超出滚动 |
| **语言** | `language` | 约束行 + `aiLanguage` 写入项目 settings |
| **内容（自由形式）** | `extra_content` | 与 `topic` 合并为 `_build_topic()` |
| **内容（逐张卡片）** | `page_contents[]` | 模板逐页列出；`topic` 作整体主题参考 |
| **附加说明** | `extra_instructions` | 非「无」时追加：`附加说明：{{ extra_instructions }}` |

### 4.6 底栏（固定视口底部）

底栏 `shrink-0` 贴视口底；根布局 `h-dvh overflow-hidden`，中栏内容独立滚动，页数增多时底栏不被推下。

| 区域 | 逻辑 |
|------|------|
| **左侧** | 正常字号展示「配额 remaining/total」 |
| **中间** | **生成** 主按钮单独页面水平居中（与顶栏标题对齐）；「共 N 张卡片」在其左侧，不与按钮作为一组居中 |
| **保存** | 右侧，`saveDraft(...)` 写入 sessionStorage，toast「草稿已保存」 |

页数在左栏「语言」下方调整（1–30）；生成页入口下拉仍为 1–10。

### 4.7 「生成」按钮 — 完整链路

1. `saveDraft(...)` 保存当前编辑器状态  
2. `POST /api/v1/项目/ai-生成`，请求体：

```json
{
  "topic": "<生成页 topic>",
  "page_count": 10,
  "audience": "<写给…>",
  "tone": "<语气>",
  "text_density": "简约|精炼|详细|繁琐",
  "language": "简体中文|English",
  "viewport_mode": "auto|web|mobile",
  "background_preset": "classic_white|light_gray",
  "extra_content": "<内容区>",
  "extra_instructions": "<附加说明>",
  "content_mode": "free|per_page",
  "page_contents": ["第1页…", "第2页…"],
  "theme_id": "zjy-minimal|eqxiu-story|tech-blue|…（12 套，见 designThemes.js）",
  "model": "gpt-5.5"
}
```

**逐张卡片模式校验**：至少 1 页非空；`page_contents.length === page_count`。

3. 写入 `sessionStorage.ai_generate_job` → 立即跳转 `/create/generate/result/_pending`（Review **无**全屏遮罩）  
4. 结果页展示 **「加载中…」**（`DeckGenerateOverlay`，预估 `8 + pageCount × 4` 秒）→ `POST /api/v1/项目/ai-生成`  
5. 后端消耗 1 次 AI 配额 → 渲染 `全量生成.yaml` → LLM → 解析 JSON → 创建项目；`theme_id` 写入 settings，默认主题渐变背景  
6. 成功后 `replace` 至 `/create/generate/result/:publicId`；**直接使用 ai-生成 响应灌入编辑器**（避免重复 `getProject`），画笔 **「正在绘制…」** 揭示动画 → 可编辑

**LLM 系统提示结构（摘要）：**

```
约束：页数为 N；语言为 …；文本密度为 …；…
[free] 分页模式：自由形式。请根据页数与风格自行将主题内容合理分页。
      主题：{topic + extra_content 合并}
[per_page] 分页模式：逐张卡片。必须恰好 N 页，第 i 页严格对应「第 i 页」文本。
           整体主题参考：{topic}
           --- 第 1 页 --- …
受众：…
风格：{密度描述；语气：…}
```

失败：结果页展示错误条与「返回编辑」，清除生成任务。

**Review 页不再展示全屏等待遮罩**；点击「生成」后立即跳转结果页 pending 路由。

### 4.8 生成结果页（`/create/generate/result/:publicId`）

**组件：** `AiGenerateResult.vue` + `DeckEditorWorkspace`（`layout-mode="result"`）

**三级导航：** `/create/generate` → `/create/generate/review` → `/create/generate/result/:publicId`（或先 `/result/_pending`）

**生成动线（2026-05-31）：**

1. Review 点「生成」→ 写入 `sessionStorage.ai_generate_job` → 立即进入 `/create/generate/result/_pending`
2. 结果页居中 **「加载中…」**（`DeckGenerateOverlay`）→ `POST /api/v1/项目/ai-生成`
3. 成功后 `replace` 至真实 `public_id`，用 API 响应 **initialProject** 灌入 workspace（同一切换内不再重复拉取），**「正在绘制…」** 画笔动画逐页/逐组件揭示（可「跳过动画」）
4. 揭示完成后进入常规编辑；顶栏 **「主题」** 按钮打开右侧 **ThemeSidebarDrawer**（Gamma 风格 2 列预览卡：背景 / Title / Body&link；12 套中文主题名）

**项目标识：** 对外 URL 与 REST 路径均使用 21 位 NanoID `public_id`（如 `V1StGXR8_Z5jdHi6B-myT`），**不暴露**数据库自增 `id`。旧书签若仍带纯数字 id，路由守卫会调用 `GET /api/v1/项目/resolve/{ref}` 解析并重定向至 canonical `public_id` URL。

**API 时机：**

| 时机 | 请求 |
|------|------|
| 结果页 pending 挂载 | `POST /api/v1/项目/ai-生成`（NovAI 计费；body 来自 `ai_generate_job`） |
| 进入结果页（已有项目 / 刷新） | `GET /api/v1/项目/{public_id}`（加载 slides 与 `generation_meta`） |
| 生成成功当次进入 | 优先 **initialProject**（ai-生成响应），可跳过首次 GET |
| 编辑画布 / 标题 / 要点 / 换主题 | `PUT /api/v1/项目/{public_id}`、`PUT .../页面/:slideId`、画布保存（debounce） |
| 插入空白页 / AI 生成卡片 | `POST .../页面`（可选 `insert_after_slide_id`）、`POST .../页面/ai-生成` |

**PPT 纵览三栏布局：**

| 区域 | 内容 |
|------|------|
| 顶栏 | `ResultPageHeader`：面包屑 + 可编辑标题 + **主题**（打开右侧抽屉）、演示、UserMenu |
| 左栏 | `SlideThumbList` **compact** 横屏缩略图（web-1280），纵向展示**全部**页面缩略图，可滚动 |
| 中栏 | `ResultSlidesOverview`：**一屏约 1.5 页**满铺 16:9 卡片；选中页内联编辑；**选中组件**时 `EditorContextLayer` 浮动工具栏；**间隙 hover / 点击卡片**时在 gap 内 **absolute 胶囊插入条**（+ / AI，不占文档流高度） |
| 右栏 | 无组件选中：`ResultEditRail`（素材/背景/动效/音乐/AI）；**选中图片**时切换为 `ElementMediaPanel`（预览、裁切、适应、AI 重生成） |
| 主题抽屉 | `ThemeSidebarDrawer`：顶栏触发，右侧 overlay；`ThemePreviewCard` 展示背景色、标题字体、正文与链接色 |
| 底栏 | **保存**（落库 + 下载评估包 JSON + 复制 Markdown 摘要）、**再生成一次**（回 review） |

**无**「进入完整编辑器」入口；**无**右侧宽内容表单面板。

**默认 viewport：** AI 生成 `viewport_mode=auto` 落库为 `web-1280`（PPT 横屏）；结果页加载时若无 canvas 且仍为 mobile 会自动升级为 web-1280。

**页面背景：** 生成页所选 `background_preset`（经典白粉 → `#fafafa`、浅灰 → `#f0f2f5`、无 → 不统一铺色）写入每页 `slide.canvas_background` 与 `generation_meta.background_preset`；结果页经 `resolveSlideCanvasBackground` 统一解析。浅色背景（含经典白粉）预览使用深色文字。

**预览可读性：** AI 全量生成时 `canvas_elements` 常为空；`PreviewSlideFrame` 在浅色背景上直接渲染 title/subtitle/bullets（深色字），深色背景仍用半透明白卡片 fallback。

**评估包（人工评估，无自动打分）：** 保存时前端生成 `evaluation-{projectId}-{date}.json`，含项目、生成参数快照、逐页内容与 `evaluation_hint`（参照 `docs/ppt-master-benchmark/evaluation-rubric.md` Phase1 维度 1–6）。用户将文件或剪贴板内容发给助手人工打分。

**API 响应：** `ProjectOut.generation_meta` 为 `{ model, channel, duration_ms, background_preset }`。

## 五、图片路径（`/create/generate/image`）

**布局：** 桌面端 `lg:grid-cols-2` 左右等宽两栏，窄屏上下堆叠；左右栏始终同时可见（无 form/result 整页切换）。

| 区域 | 控件 | 逻辑 |
|------|------|------|
| 左栏 · 提示词编辑 | 提示词 textarea | 编辑 `prompt`；自生成页预填 `draft.topic` |
| 左栏 | 尺寸 | `mobile` / `web` → `viewport_preset_id` |
| 左栏 | **生成图片** | `POST /api/v1/生图/独立`；按钮 `progress_activity` 旋转加载 |

| 右栏 | 图片预览框 | 空态占位 / 生成中 spinner / 成功后加载图片 |
| 右栏 | 点击图片 | 打开 `ImageCropModal` 裁切 |
| 右栏 | **复制** | 剪贴板写入图片（fallback 链接） |
| 顶栏 | **返回首页** | `/create/generate` |

**独立生图链路：**

1. `generateStandaloneImage({ prompt, viewport_preset_id, fit_mode, tier })`
2. 扣 AI 配额，`GenerationLog.project_id = null`
3. 页面展示结果预览，**不进入编辑器**

## 九、后端 API 速查

| 端点 | 触发按钮 | 配额 |
|------|----------|------|
| `POST /api/v1/项目/ai-生成` | 提示编辑器「生成」 | 是 |
| `GET /api/v1/项目/resolve/{ref}` | 路由守卫（数字 id → public_id 重定向） | 否 |
| `GET/PUT/DELETE /api/v1/项目/{public_id}` | 编辑器 / 结果页 / Dashboard | 否 |
| `POST /api/v1/项目/导入-pptx` | Dashboard「导入 PPT」 | 否 |
| `POST /api/v1/生图/独立` | 生成图片页「生成图片」 | 是 |
| `POST /api/v1/项目` | 图片页创建空项目 | 否 |

> 项目相关 REST 路径段均为 `{public_id}`；响应体 `ProjectOut` 含 `public_id` 字段。分享链接仍为 `/s/{share_slug}`，与 `public_id` 并存。
