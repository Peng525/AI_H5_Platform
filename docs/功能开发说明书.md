### 1.1 功能范围

| 模块 | 路由/组件 | 说明 |
|------|-----------|------|

### 1.2 草稿状态（sessionStorage）

键名：`ai_create_draft`（见 `useAiCreateDraft.js`）

| 字段 | 默认值 | 写入时机 |
|------|--------|----------|
| `type` | `deck` | 第 1 步选类型 |
| `pageCount` | `10` | 第 1 步 / 第 3 步底栏 |
| `background` | `classic_white` | 第 1 步 |
| `viewportMode` | `auto` | 第 1 步 |
| `language` | `简体中文` | 第 1 步 / 第 3 步 |
| `topic` | `''` | 第 2 步「继续」 |
| `textDensity` | `精炼` | 第 3 步 |
| `audience` | `''` | 第 3 步 |
| `tone` | `专业、清晰、具说服力` | 第 3 步 |
| `extraContent` | `''` | 第 2/3 步 |
| `extraInstructions` | `''` | 第 3 步 |
| `contentMode` | `free` | 第 3 步：`free` / `per_page` |
| `cardSplitMode` | `null` | 第 3 步：`auto` / `manual` |
| `pageContents` | `[]` | 第 3 步逐张卡片各页文本 |

## 四、第 3 步 — 提示编辑器（`/create/generate/review`）

**组件：** `frontend/src/views/create/AiGenerateReview.vue`

**前置：** 无 `topic` 时 `router.replace('/create/generate/prompt')`。

### 4.1 顶栏

| 按钮 | 逻辑 |
|------|------|
| **上一步** | `/create/generate/prompt` |

### 4.2 移动端 Tab（`< lg`）

| Tab | 显示区域 |
|-----|----------|
| 设置 | 左栏：文本量、受众、语气、语言 |
| 内容 | 中栏：扩写内容 |
| 说明 | 右栏：附加说明 |

桌面端三栏同时展示。

### 4.3 文本量四按钮（核心）

| 按钮 | 点击逻辑 | 是否立即请求 AI |
|------|----------|-----------------|
| **简约** | `textDensity = '简约'` | 否 |
| **精炼** | `textDensity = '精炼'`（默认） | 否 |
| **详细** | `textDensity = '详细'` | 否 |
| **繁琐** | `textDensity = '繁琐'` | 否 |

选中态：主色边框 + 浅蓝底。

**仅在点击「生成」时** 随请求体发送 `text_density`。后端映射（`deck_generation_service.py`）：

| 值 | 写入 LLM `style` 字段的文案 |
|----|------------------------------|
| 简约 | 简洁明了，每页要点极少 |
| 精炼 | 精炼专业，重点突出 |
| 详细 | 详细展开，信息充实 |
| 繁琐 | 详尽全面，覆盖细节 |

同时在 `全量生成.yaml` 约束行出现：`文本密度为 {{ text_density }}`（原始中文值）。

### 4.4 内容栏双模式

内容栏头部 Segmented 切换：**自由形式**（默认） / **逐张卡片**。

| 模式 | UI | 生成行为 |
|------|-----|----------|
| **自由形式** | 单个 textarea，`extraContent` | `content_mode: free`；`topic` + `extra_content` 合并；LLM 按页数与风格自行分页 |
| **逐张卡片** | N 个带「页面 i」badge 的 textarea | `content_mode: per_page`；`page_contents[]` 与 `page_count` 等长；LLM 严格 1 页对应 1 段 |

**切换到逐张卡片**（首次）：弹出 `CardSplitModeDialog`：

| 按钮 | 逻辑 |
|------|------|
| **自动分页** | 调用 `splitContentIntoPages(extraContent, pageCount)`：按 `# 标题`、中文序号、`1.` 数字序号、双换行段落切分，再归一化到 N 段 |
| **自行分页** | `pageContents = N 个空字符串` |
| **取消** | 不切模式 |

**自动分页规则**（`frontend/src/utils/splitContentIntoPages.js`）：

1. 段数 > N：合并相邻最短段  
2. 段数 < N：拆分最长段直至 N 段  
3. 空文本：N 个空白框  

**切回自由形式**：`pageContents.filter(Boolean).join('\n\n')` 写回 `extraContent`，清空 `cardSplitMode`。

**页数 ± 与逐张卡片**：增减 `pageCount` 时 `syncPageContents` 对齐数组；减少且末尾页有内容时 ConfirmDialog 确认丢弃。

### 4.5 其他设置控件

| 控件 | 草稿/API 字段 | 发给 LLM 的方式 |
|------|---------------|-----------------|
| **写给…** | `audience` | 模板变量 `受众：{{ audience }}` |
| **语气** | `tone` | 拼入 `style`：`语气：{tone}` |
| **语言** | `language` | 约束行 + `aiLanguage` 写入项目 settings |
| **内容（自由形式）** | `extra_content` | 与 `topic` 合并为 `_build_topic()` |
| **内容（逐张卡片）** | `page_contents[]` | 模板逐页列出；`topic` 作整体主题参考 |
| **附加说明** | `extra_instructions` | 非「无」时追加：`附加说明：{{ extra_instructions }}` |

### 4.6 底栏

| 按钮 | 逻辑 |
|------|------|
| **−** | `pageCount = max(1, pageCount - 1)` |
| **+** | `pageCount = min(30, pageCount + 1)` |
| **生成** | 见 §4.7 |

页数显示：`{pageCount} 张卡片`（前端可调到 30，第 1 步下拉仍为 1–10）。

### 4.7 「生成」按钮 — 完整链路

1. `saveDraft(...)` 保存当前编辑器状态  
2. `POST /api/v1/项目/ai-生成`，请求体：

```json
{
  "topic": "<第2步 topic>",
  "page_count": 10,
  "audience": "<写给…>",
  "tone": "<语气>",
  "text_density": "简约|精炼|详细|繁琐",
  "language": "简体中文|English",
  "viewport_mode": "auto|web|mobile",
  "background_preset": "classic_white|light_gray",
  "extra_content": "<内容区>",
  "extra_instructions": "<附加说明>",
  "content_mode": "free|per_page",
  "page_contents": ["第1页…", "第2页…"]
}
```

**逐张卡片模式校验**：至少 1 页非空；`page_contents.length === page_count`。

3. 后端消耗 1 次 AI 配额 → 渲染 `全量生成.yaml` → LLM → 解析 JSON → 创建项目与 slides  
4. 前端 `applyProjectSettingsLocal` + `clearDraft()` → `/editor/:id`

**LLM 系统提示结构（摘要）：**

```
约束：页数为 N；语言为 …；文本密度为 …；…
[free] 分页模式：自由形式。请根据页数与风格自行将主题内容合理分页。
      主题：{topic + extra_content 合并}
[per_page] 分页模式：逐张卡片。必须恰好 N 页，第 i 页严格对应「第 i 页」文本。
           整体主题参考：{topic}
           --- 第 1 页 --- …
受众：…
风格：{密度描述；语气：…}
```

失败：底栏显示 `error`，`generating` 复位，可重试。

### 7.4 Dashboard 内容区（`/dashboard`）

**组件：** `Dashboard.vue` · `ProjectCoverThumb.vue` · `usePptImport.js`

| 区域 | 控件 | 逻辑 |
|------|------|------|
| 标题 | **项目** | 页面主标题 |
| 标题下方 | **+ 新建演示**（主按钮）、**导入 PPT**（左）；**批量删除**（右） | 同行左右分列 |
| 项目卡片 | 缩略图 + 标题 + 相对时间 | `...` 菜单：编辑 / 预览 / 删除 |

主内容区背景为 **白底**（`WorkbenchShell` 右侧列）。已移除 Tab 筛选与搜索框。

**按钮样式：** **新建演示** 为蓝底白字主按钮（`bg-primary text-on-primary`，与侧栏「全部项目」一致）；**导入 PPT** 及批量操作中的次要按钮为白底黑字 + 灰边框；批量删除与「删除选中」为红底白字。

**字号：** 页面主标题「项目」与卡片标题保持原有强调级别；其余正文、按钮、元数据（相对时间）、空状态文案、批量选择提示等统一为 `text-sm`。

导入限制：仅 `.pptx`；失败显示内容区红色提示。
