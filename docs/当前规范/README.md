# 当前规范 / Current Specs

> **本文件不是规范，而是目录策略说明。** 它只回答一个问题：什么文档有资格进入本目录。

---

## 一、定位

本目录存放**已确认与当前源码一致**的规范性文档，对应 `docs/README.md` 中「当前实现依据优先级」的第 5 级。

它回答的是「**系统现在是什么样**」，因此必须与源码一致。

> 注意区分：
> - `项目决策记录/`（ADR）回答「**当初为什么这么决定**」—— 不属于本目录
> - `旧方案/` 回答「**曾经怎么做**」—— 不属于本目录
> - `开发计划/` 回答「**本轮具体做什么**」—— 不属于本目录

---

## 二、准入标准

一份文档要进入本目录，**必须同时满足 A / B / C**：

| 编号 | 标准 | 判定方法 |
|---|---|---|
| **A** | **没有历史链路冒充当前链路** | 反例：文档仍称「`严格模板生成.yaml` 是当前按钮 Prompt」，而源码实际使用 `orchestrate_strategist.yaml` → 不通过 |
| **B** | **与 Accepted ADR 不冲突** | Design Token、Layout Family、图片策略等必须符合 `项目决策记录/` 中 `状态：Accepted` 的当前决策 |
| **C** | **有明确状态与核验记录** | 顶部需带三行元数据：`状态：Current` / `最后核验：YYYY-MM-DD` / `核验依据：G0 · G2 · ADR-xxx` |
