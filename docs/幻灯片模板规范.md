# 幻灯片模板规范

本文档定义 AI 全量生成与前端 `SlideTemplateEngine` 共用的结构化幻灯片契约。

## 原则

- AI **只输出 JSON**（`template` + `modules` / `headline`），不输出 HTML 或 CSS class
- 排版由 [`slide-templates/`](../frontend/src/slide-templates/) Vue 组件（Tailwind）与 [`compileStructuredSlide.js`](../frontend/src/utils/compileStructuredSlide.js) 接管
- **禁止**整页单调 `bullets` 列表

## template 枚举

| template | 场景 | modules |
|----------|------|---------|
| `cover` | 封面 | 0 |
| `section` | 章节/背景/目标过渡 | 0–1 |
| `grid_2x2` | 核心问题、平台定位四宫格 | 4 |
| `split_lr` | 左文右图表占位 | 2 |
| `cards_row` | 3–4 信息卡片横排 | 3–4 |
| `stat_hero` | 核心数据结论 | 1（stat+desc） |
| `steps` | 三步流程 | 3 |
| `quote` | 金句 | quote/author 字段 |
| `closing` | 致谢 | contact |

## module 字段

```json
{
  "icon": "target",
  "title": "背景",
  "body": "说明文字",
  "emphasis": "关键词",
  "stat": "128%",
  "desc": "同比提升",
  "role": "text|chart_placeholder"
}
```

## 编译与测量

- 无 `canvas_elements` 时，前端 `load()` 调用 `compileStructuredSlide`
- 文本高度经 [`measureTextBlock.js`](../frontend/src/utils/measureTextBlock.js) 预测量，避免 canvas 绝对坐标重叠
- `split_lr` 右栏占位使用 `chartPlaceholder` 类型，`z-index` 低于正文且 `pointer-events: none`
