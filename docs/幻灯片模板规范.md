# 幻灯片模板规范

本文档定义 AI 全量生成与前端 `SlideTemplateEngine` 共用的结构化幻灯片契约。

## 原则

- AI **只输出 JSON**（`template` + `modules` / `headline` / `image_prompt`），不输出 HTML、CSS class 或画布坐标
- 排版由 [`compileStructuredSlide.js`](../frontend/src/utils/compileStructuredSlide.js) 接管；`canvas_elements` 入库时**一律为空**，禁止 LLM 坐标污染
- **禁止**整页单调 `bullets` 列表
- 编译器版本 `STRUCTURED_COMPILE_VERSION`（当前 **3**）变更时，前端自动对含 `structured.template` 的历史页重编译

## template 枚举

| template | 场景 | modules | 配图 |
|----------|------|---------|------|
| `cover` | 封面 | 0 | 必填 slide 级 `image_prompt` → 后端生成 `image_url` |
| `section` | 章节/背景/目标过渡 | 0–1 | — |
| `grid_2x2` | 核心问题、平台定位四宫格 | 4 | — |
| `split_lr` | 左文右场景图 | 2 | 右栏 `role: scene_image` + `image_prompt` |
| `cards_row` | 3–4 信息卡片横排 | 3–4 | — |
| `stat_hero` | 核心数据结论 | 1（stat+desc） | — |
| `steps` | 三步流程 | 3 | — |
| `quote` | 金句 | quote/author 字段 | — |
| `closing` | 致谢 | contact | — |

## slide 与 module 字段

**页级（cover 等）：**

```json
{
  "template": "cover",
  "title": "演示标题",
  "subtitle": "副标题",
  "image_prompt": "香港中学教师在智慧教室查看错题分析大屏",
  "image_url": "https://…"
}
```

**module：**

```json
{
  "icon": "target",
  "title": "背景",
  "body": "说明文字，≤120 字",
  "emphasis": "关键词",
  "stat": "128%",
  "desc": "同比提升",
  "role": "text|scene_image|chart_placeholder",
  "image_prompt": "split_lr 右栏场景描述，≤120 字",
  "image_url": "https://…"
}
```

- `chart_placeholder`：仅在有**真实数据图表**时使用；无数据时**禁止**，优先 `scene_image`
- `image_url` 由后端 `_enrich_slide_images` 写入，前端编译器只读

## 生成管线（配图）

```
LLM JSON → _extract_structured_slide → _enrich_slide_images → seed_project_slides
```

1. LLM 输出 `image_prompt`（cover 页级；split_lr 右栏 module 级）
2. `deck_generation_service._enrich_slide_images` 在入库前调用 `generate_image`（与编辑器 AI 配图同通道）
3. 失败时 fallback：`picsum.photos/seed/{md5(prompt)}`，**不** fallback 到图表占位
4. 配额：每 deck 最多 `page_count // 2 + 1` 张（cover + 各 split_lr）
5. `settings.generationMeta.images_generated` 记录成功张数

## 编译与测量

- 无 `canvas_elements` 或 `_compileVersion` 过期时，前端 `ensureSlideCompiled` 调用 `compileStructuredSlide`
- 文本经 [`measureTextBlock.js`](../frontend/src/utils/measureTextBlock.js) 预测量；页眉用 `stackPageHeader`，卡片/正文用 `fitTextInBox`（自动换行 → 缩字号 → 截断）
- `grid_2x2` 宽屏为**真 2×2** 网格；module 不足 4 个时后端 pad 占位 module
- `split_lr` 默认右栏 `imageEl`；仅 `role === 'chart_placeholder'` 且无 prompt/url 时显示 `chartPlaceholder`（兼容旧数据）
- `cover` 左/右分栏：`st.image_url` 或 picsum seed
