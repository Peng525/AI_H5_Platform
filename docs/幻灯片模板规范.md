# 幻灯片模板规范

本文档定义 AI 全量生成与前端编译引擎共用的结构化幻灯片契约。

## 两套模板系统

项目现包含两套并行的模板系统：

| 系统 | Prompt | 字段 | 模板数 | 适用场景 |
|------|--------|------|--------|----------|
| **固定布局**（旧） | `固定布局生成.yaml` | `layout_id` | 8 种 | 复杂排版、图表、路线图 |
| **严格模板**（新，默认） | `严格模板生成.yaml` | `template_type` | 6 种 | 商务汇报、AI 最少参与 |

> 用户通过 `strict_template_mode` 字段控制（默认 `true` 使用严格模板）。

## 原则

- AI **只输出 JSON 文本内容**，不输出 HTML、CSS class、画布坐标、图标名称
- **图标由前端 `matchIcon.js` 自动匹配**（中文关键词→Material Symbol）
- **图片由后端 Unsplash/Pexels 素材库搜索**（中文关键词→英文翻译→API 搜索），替代 AI 生图
- 排版由 `compilePptTemplateSlide.js` 接管；`canvas_elements` 入库时为空
- 编译器版本变更时，前端自动重编译

## 严格模板枚举（推荐）

| template_type | 用途 | variant | 配图 | AI 需输出的字段 |
|---------------|------|---------|------|----------------|
| `title_page` | 封面/结束页 | — | PPT 深蓝渐变背景 | `title`, `subtitle`, `author`, `date` |
| `toc` | 目录页 | — | 浅灰卡片列表 | `title`, `items[{num, title}]` |
| `points` | 纯文字要点 | 2-5（自动计算） | ❌ | `title`, `points[{text}]` |
| `cards` | 纯文字卡片 | 1-4（自动计算） | ❌ | `title`, `cards[{title, body}]` |
| `image_text_left` | 左图右文 | 1-4 | ✅ Unsplash 搜索 | `title`, `image_topic`, `points/cards` |
| `image_text_right` | 左文右图 | 1-4 | ✅ Unsplash 搜索 | `title`, `image_topic`, `points/cards` |

> **AI 不需要输出 `icon`、`variant`、`image_query`(英文)** — 全部由系统自动处理。

## AI 最少参与设计

| 字段 | 谁负责 | 方式 |
|------|--------|------|
| `icon` | 前端 | `matchIcon.js` 中文关键词→Material Symbol 规则匹配 |
| `variant` | 后端 | `len(points)` 或 `len(cards)` 自动计算 |
| `image_query`(英文) | 后端 | 中文→英文词典翻译（`image_search_service.py`） |
| 图片 URL | 后端 | Unsplash/Pexels API 搜索（0.3-2秒/张） |
| 布局坐标 | 前端 | `pptTemplateLayout.js` 预设坐标常量 |
| 背景美化 | 前端 | PPT 模板 SVG（深蓝渐变、装饰线、页码） |

## 内容切分：一节一页

`splitContentIntoPages.js` 已重写为语义感知版本：
- 按 H1/H2 标题层级切分
- H3 子节合并到父节，不独立占页
- **绝不对半切开一个标题的内容**
- 多余页面留空，交 AI 自由发挥

## 图片搜索流程

```
AI输出: image_topic: "固态电池 实验室"
  ↓
后端翻译: 固态电池→solid state battery, 实验室→laboratory
  ↓
Unsplash API 搜索: "solid state battery laboratory" (~0.5秒)
  ↓ 失败 → Pexels API (~1秒)
  ↓ 失败 → 中文原词重试
  ↓
写入 Slide.structured.image_url
  ↓
前端编译器渲染: 左侧42%宽图片 + 右侧内容区
```

> 需配置环境变量 `UNSPLASH_ACCESS_KEY`（免费申请：https://unsplash.com/developers）

## 固定布局枚举（旧，保留兼容）

| template | 场景 | modules | 配图 |
|----------|------|---------|------|
| `cover` | 封面 | 0 | `image_intent=cover_bg` |
| `section` | 章节/背景 | 0–1 | 禁止 |
| `grid_2x2` | 四宫格 | 4 | 禁止 |
| `split_lr` | 左文右栏 | 2 | `image_intent=scene` |
| `cards_row` | 横排卡片 | 3–4 | 禁止 |
| `stat_hero` | 核心数据 | 1 | 禁止 |
| `steps` | 三步流程 | 3 | `image_intent=roadmap` |
| `quote` / `closing` | 金句/致谢 | — | 禁止 |
