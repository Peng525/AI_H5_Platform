# 幻灯片模板规范

本文档定义 AI 全量生成与前端 `SlideTemplateEngine` 共用的结构化幻灯片契约。

## 原则

- AI **只输出 JSON**（`template` + `modules` / `headline` / `image_intent`），不输出 HTML、CSS class 或画布坐标
- 排版由 [`compileStructuredSlide.js`](../frontend/src/utils/compileStructuredSlide.js) 接管；`canvas_elements` 入库时**一律为空**
- **禁止**整页单调 `bullets` 列表
- 编译器版本 `STRUCTURED_COMPILE_VERSION`（当前 **5**）变更时，前端自动对含 `structured.template` 的历史页重编译

## template 枚举

| template | 场景 | modules | 配图 |
|----------|------|---------|------|
| `cover` | 封面 | 0 | 默认无图；`image_intent=cover_bg` + `image_prompt` 时全页背景图 |
| `section` | 章节/背景 | 0–1 | 禁止配图 |
| `grid_2x2` | 四宫格 | 4 | 禁止配图 |
| `split_lr` | 左文右栏 | 2 | 默认右栏纯文字；`image_intent=scene` + `image_prompt` 时情景图 |
| `cards_row` | 横排卡片 | 3–4 | 禁止配图 |
| `stat_hero` | 核心数据 | 1 | 禁止配图 |
| `steps` | 三步流程 | 3 | 可选 `image_intent=roadmap` 底栏路线图 |
| `quote` / `closing` | 金句/致谢 | — | 禁止配图 |

## image_intent 选择性配图

| 值 | 适用 template | 说明 |
|----|---------------|------|
| `none` | 默认 | 页面背景由主题渐变承担，不生图 |
| `cover_bg` | cover | 全页背景图 + 居中标题 |
| `scene` | split_lr 右栏 module | 情景/场景配图 |
| `roadmap` | steps | 底部流程路线图 |

仅当 LLM 显式声明 `image_intent` 且提供 `image_prompt` 时，后端 `_enrich_slide_images` 才调用生图 API；失败不写 `image_url`，**不用随机图**。

## 编译要点

- **cover**：默认 `buildCoverClassic` 居中文字，主题渐变由 `slide.canvas_background` 透出；`cover_bg` + `image_url` 时全幅背景图 + 遮罩
- **split_lr**：无 `image_url` 时左栏扩满全宽，不保留空右栏
- **grid_2x2 / cards_row**：卡片背景统一 `colors.bgMuted`
- 文本经 `fitTextInBox` 防止溢出
