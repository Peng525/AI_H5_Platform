# 部署说明

## 本地 Docker（推荐）

```bash
cd develop
cp .env.example .env
docker compose up -d --build
```

访问 http://localhost:8080

- 演示用户：`demo@ai-h5.com` / `demo123456`
- 管理员：`admin@ai-h5.com` / `admin123456` → 管理控制台 `/admin`
- 管理员在 `/settings` 修改的配置会写入宿主机 `develop/.env`（需 compose 挂载，已默认配置）

### AI 配图（编辑器）

1. 在 `.env` 配置中转或官方 API（至少一项），并设置 `LLM_IMAGE_MODEL_FREE` / `LLM_IMAGE_MODEL_PRO`（Gemini 配图模型常用 `-image-preview` 后缀）。
2. 登录后进入 `/editor/:id`，右侧 AI 面板输入画面描述，点击 **「生成配图」**。
3. 生成结果在面板下方预览，可 **添加到页面**（适应宽度 / 填充页面 / 原始尺寸）或 **复制** 到剪贴板。
4. 每次配图消耗免费档配额（与文案生成共用次数）；Pro 会员不限次。

功能需求见 [需求清单.md](./需求清单.md)。

### 五项功能冒烟（本地）

1. **登录**：`demo@ai-h5.com` / `demo123456` → 探索模板
2. **支付**：`/upgrade` → 选择套餐 → 「演示：模拟支付成功」→ 配额更新
3. **管理**：`admin@ai-h5.com` / `admin123456` → `/admin` 仪表盘、用户管理
4. **H5 模板**：`/admin/templates` 新建/编辑/上下架
5. **提示词**：`/admin/prompts` 编辑 system/user 提示词

微信/支付宝扫码在本地环境会提示使用演示支付。

### Docker Hub 拉取失败（国内常见）

若报错 `auth.docker.io` / `connectex` 超时，请任选：

```powershell
# 使用国内基础镜像构建
docker compose -f docker-compose.yml -f docker-compose.cn.yml up -d --build
```

或不用 Docker：

```powershell
.\scripts\start-local.ps1
```

详见 [DockerHub连接失败.md](./DockerHub连接失败.md)

## 云端（AWS EC2 等）— 延后可选

1. 安装 Docker 与 docker-compose
2. 克隆仓库 `develop` 分支
3. 配置 `.env` 与安全组开放 8080（或 Nginx 反代 443）
4. `docker compose up -d --build`

> 本期以本地 Docker 为主；云端部署与真实支付回调见需求清单延后项。

## Nginx 反代示例（可选）

```nginx
server {
    listen 80;
    server_name your-domain.com;
    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```
