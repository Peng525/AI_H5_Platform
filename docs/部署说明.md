# 部署说明

## 本地 Docker（推荐）

```bash
cd develop
cp .env.example .env
docker compose up -d --build
```

访问 http://localhost:8080

**对话生成器 / 文字云等新前端功能**：无需在本机安装 Node.js；改代码后重新构建镜像即可（见下文「更新版本」）。

- 演示用户：`demo@ai-h5.com` / `demo123456`
- 管理员：`admin@ai-h5.com` / `admin123456` → 管理控制台 `/admin`
- 管理员在 `/settings` 修改的配置会写入宿主机 `develop/.env`（需 compose 挂载，已默认配置）

### 个人用户最小配置

无需微信商户号、无需短信。`.env` 只需：

```env
JWT_SECRET=随机长字符串
CAPTCHA_PROVIDER=mock
ADMIN_USERNAMES=admin@ai-h5.com
WECHAT_PERSONAL_QR_URL=/static/wechat-pay-qr.png
```

将微信个人收款码保存为 `backend/pay_assets/wechat-pay-qr.png`（推荐，不会被前端 build 清空）。

### 五项功能冒烟（个人用户）

1. **登录**：`CAPTCHA_PROVIDER=mock` → 开发模式验证 → `demo@ai-h5.com` / `demo123456`（仅邮箱）
2. **支付**：`/upgrade` → 微信扫码 → 展示收款码 + 金额 → 你微信收到款 → `/admin` 确认收款
3. **管理**：确认收款后用户端自动开通；或在 `/admin/users` 直接改 Pro
4. **H5 模板**：`/admin/templates` — 编辑元数据与 `slides_json`；支持 **上传 .pptx 解析** 并勾选上架后出现在探索模板页
5. **提示词**：`/admin/prompts`

开发测试可用升级页底部「演示：跳过支付」。

### 更新版本（Docker 用户）

拉取或修改代码后，在 `develop` 目录执行：

```bash
docker compose up -d --build
```

国内 Docker Hub 较慢时：

```bash
docker compose -f docker-compose.yml -f docker-compose.cn.yml up -d --build
```

说明：

- 前端依赖（`html2canvas`、`wordcloud`、`xlsx` 等）在 **镜像构建阶段** 由 `npm install` 自动安装，宿主机不必单独跑 `npm install`。
- 构建产物写入镜像内 `backend/static/`，由 uvicorn 一并提供。
- **画布多选、响应式编辑器、探索模板小屏适配** 等纯前端改动：同样执行 `docker compose up -d --build` 后刷新浏览器即可。
- 数据库与模板：容器启动时会 sync `backend/data/h5_templates/*.json` 到 SQLite（挂载目录 `./data`）。若模板试看异常，重建并重启容器后刷新 `/templates` 即可。
- 仅改了 `.env` 时：`docker compose up -d`（无需 `--build`），或 `docker compose restart app`。

### 背景音乐（BGM）

1. 将 MP3 放入 **`backend/static/bgm/`**（或运行 `.\scripts\install-bgm.ps1` 安装测试曲）
2. 编辑器 → **工具箱 → 音乐** → 点击「启用背景音乐」→ 在列表中选择曲目
3. 幻灯片画框内右上角出现旋转唱片按钮：播放时旋转，点击可静音/继续（预览与分享页同样支持）
4. 曲目列表来自 `GET /api/v1/bgm/曲目`（扫描 `static/bgm/*.mp3`）

### 画布版式与层级

1. **素材 → 版式**：点击标题 / 章节页 / 三要点 / 表格或「其他」中的版式，会将该版式**叠加**到当前页画布（不清空已有组件、不改变页面背景色）
2. **新建页面**：仍通过版式选择器**整页套用**（含默认背景），或选空白页
3. **层级**：页面背景色始终最底；全页背景图元素 `zIndex=0`；正文组件从 `10` 起。选中组件后，画布顶部工具栏可 **置顶 / 置底 / 上移一层 / 下移一层**
4. 纯前端改动：重建前端容器后刷新浏览器即可（见上文「仅前端改动」）

### 管理端版式（自定义模板）

1. 管理员登录 → **管理控制台 → 版式管理**（`/admin/layouts`）
2. **新建版式**：填写 ID、名称、Material 图标、分组与展示位置（主屏快捷 / 更多版式弹窗）
3. 粘贴 **手机端** `canvas_elements` JSON（可选填网页端）；可从编辑器当前页导出元素后粘贴
4. 勾选 **启用** 并保存 → 用户在编辑器 **素材 → 版式** 中可见并使用（叠加到当前页）
5. 涉及后端新表 `layout_blocks`：需 `docker compose up -d --build` 重建后启动

### 互动组件入口（编辑器）

登录 → 打开项目 → **工具箱 → 素材 → 互动组件**：

| 功能 | 说明 |
|------|------|
| 对话生成器 | 全屏三栏（预设/预览/设置）；播放方式点击或自动；逐句间隔 100～60000 ms；「插入当前页」→ 预览/分享播放 |
| 文字云 | 手动词或粘贴 `选项,票数` 表格 → 选形状 → 插入幻灯片 |

### 微信个人收款码 + 后台确认（默认收款流程）

1. 收款码放到 `backend/static/wechat-pay-qr.png`（或 `.env` 填 `WECHAT_PERSONAL_QR_URL`）
2. 用户 `/upgrade` →「微信扫码支付」→ 按页面金额转账
3. **你在微信 App 收到到账通知** → `/admin`「待支付订单」→ 核对 **订单号 #N、用户 ID、金额** →「确认收款」
4. 用户升级页轮询显示「套餐已开通」
5. **补发/赠送**：也可在 `/admin/users` 直接将用户改为 Pro，无需订单

**安全提示**：个人码通常长期有效；请保管好管理员密码与服务器，仅在实际到账后确认收款；勿将 `CAPTCHA_PROVIDER=mock` 用于对外生产环境。

### 腾讯云拼图（上线推荐）

1. [验证码控制台](https://console.cloud.tencent.com/captcha) 创建 Web 验证
2. `.env`：
   ```env
   CAPTCHA_PROVIDER=tencent
   TENCENT_CAPTCHA_APP_ID=你的AppId
   TENCENT_CAPTCHA_APP_SECRET_KEY=你的SecretKey
   ```
3. 登录仅需 **邮箱 + 密码 + 拼图**（本期不支持手机号）

### AI 配图（编辑器）

1. 在 `.env` 配置中转或官方 API，并设置 `LLM_IMAGE_MODEL_FREE` / `LLM_IMAGE_MODEL_PRO`
2. 登录后进入 `/editor/:id`，右侧 AI 面板 →「生成配图」
3. 每次配图消耗免费档配额；Pro 会员不限次

功能需求见 [需求清单.md](./需求清单.md)。

### 中转 API 额度（NovAI 示例）

```env
LLM_RELAY_BASE_URL=https://us.novaiapi.com/v1
LLM_RELAY_API_KEY=你的密钥
RELAY_QUOTA_PROFILE=novai
RELAY_NOVAI_DASHBOARD_URL=https://once-cf.novai.su
RELAY_DASHBOARD_RECHARGE_URL=https://once-cf.novai.su/wallet
```

### 延后：微信商户 Native + ngrok

有商户号时再配置 `WECHAT_PAY_*` 与 ngrok 回调 URL。代码已保留 `wechat_native` 与 `/api/v1/支付/回调/wechat`，个人用户默认使用 `wechat_qr` 即可。

### Docker Hub 拉取失败（国内常见）

```powershell
docker compose -f docker-compose.yml -f docker-compose.cn.yml up -d --build
```

或：`.\scripts\start-local.ps1` — 详见 [DockerHub连接失败.md](./DockerHub连接失败.md)
