# 部署说明

## 本地 Docker（推荐）

```bash
cd develop
cp .env.example .env
docker compose up -d --build
```

访问 http://localhost:8080

### Docker Hub 拉取失败（国内常见）

若报错 `auth.docker.io` / `connectex` 超时，请任选：

```powershell
# 使用国内基础镜像构建
docker compose -f docker-compose.yml -f docker-compose.cn.yml up -d --build
```

或不用 Docker：

```powershell
.\scripts\start-local.ps1
```

详见 [DockerHub连接失败.md](./DockerHub连接失败.md)

## 云端（AWS EC2 等）

1. 安装 Docker 与 docker-compose
2. 克隆仓库 `develop` 分支
3. 配置 `.env` 与安全组开放 8080（或 Nginx 反代 443）
4. `docker compose up -d --build`

## Nginx 反代示例（可选）

```nginx
server {
    listen 80;
    server_name your-domain.com;
    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

## 数据持久化

SQLite 与导出文件位于 `./data`，已在 `docker-compose.yml` 中挂载。
